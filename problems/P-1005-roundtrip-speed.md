# ที่มา: เทพฟิสิกส์ฯ (รัชพล/อมร) บทที่ 1 การเคลื่อนที่ในแนวเส้นตรง — external (รอตรวจคำตอบ)
id: P-1005
หัวข้อ: จลนศาสตร์
ระดับชั้น: ม.6
หัวข้อย่อย: ความเร็วเฉลี่ย-อัตราเร็วเฉลี่ย
ระดับความยาก: 3
โจทย์: เก่งขับรถจากเมือง A ไปเมือง B ด้วยอัตราเร็วเฉลี่ย 80 กิโลเมตรต่อชั่วโมง และขับกลับจาก B ไป A ด้วยอัตราเร็วเฉลี่ย 120 กิโลเมตรต่อชั่วโมง โดยไม่หยุดพัก อัตราเร็วเฉลี่ยตลอดการเดินทางไปกลับมีค่าเท่าใด
ตัวเลือก A: 96 km/hr
ตัวเลือก B: 98 km/hr
ตัวเลือก C: 100 km/hr
ตัวเลือก D: 102 km/hr
ตัวเลือก E: 120 km/hr
คำตอบ: A
เฉลย: ระยะทางไปกลับเท่ากัน (ให้เป็น d) อัตราเร็วเฉลี่ยรวม = ระยะทางรวม/เวลารวม = 2d / (d/80 + d/120) = 2 / (1/80 + 1/120) = 96 km/hr (ค่าเฉลี่ยฮาร์มอนิก)
trap: ตอบ C — เอา (80+120)/2 = 100 (เฉลี่ยเลขคณิตธรรมดา) ซึ่งผิดเพราะเวลาที่ใช้แต่ละเที่ยวไม่เท่ากัน
