# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2014
หัวข้อ: แสงและทัศนศาสตร์
หัวข้อย่อย: เลนส์ประกอบ
ระดับความยาก: 3
โจทย์: วางวัตถุห่าง 20 ซม. หน้าเลนส์บางกระจายแสง เกิดภาพเสมือนฝั่งเดียวกับวัตถุ ห่างเลนส์ 12 ซม. หากนำเลนส์รวมแสงความยาวโฟกัส 20 ซม. มาประกบติดกันเป็นเลนส์ประกอบ แล้ววางวัตถุที่ระยะเดิม ภาพที่เกิดเป็นภาพจริงหรือเสมือน และห่างเลนส์กี่เซนติเมตร
ตัวเลือก A: ภาพเสมือน, 15
ตัวเลือก B: ภาพจริง, 15
ตัวเลือก C: ภาพเสมือน, 30
ตัวเลือก D: ภาพจริง, 30
ตัวเลือก E: ภาพจริง, 60
คำตอบ: C
เฉลย: เลนส์กระจาย: $\frac{1}{f_1} = \frac{1}{20} + \frac{1}{-12} = -\frac{2}{60}$ → $f_1 = -30$ ซม. รวมกับเลนส์รวม $f_2 = 20$: $\frac{1}{f} = -\frac{1}{30} + \frac{1}{20} = \frac{1}{60}$ → $f = 60$ ซม. หาภาพ: $\frac{1}{s'} = \frac{1}{60} - \frac{1}{20} = -\frac{2}{60}$ → $s' = -30$ (ลบ = ภาพเสมือน ระยะ 30 ซม.)
trap: ตอบ D — ลืมใส่เครื่องหมายลบของภาพเสมือน ทำให้ได้ f₁ บวก แล้วสรุปเป็นภาพจริงผิด
