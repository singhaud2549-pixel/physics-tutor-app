# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2016
หัวข้อ: ไฟฟ้าสถิต
หัวข้อย่อย: พลังงานศักย์ไฟฟ้าและงานเลื่อนประจุ
ระดับความยาก: 3
โจทย์: จากรูป ประจุ $Q$ อยู่ตรงกลาง มีประจุ $q$ อยู่ทางซ้ายและด้านบน ห่างจาก $Q$ เป็นระยะ $d$ เท่ากัน หากต้องการนำประจุ $q$ อีกตัวจากระยะอนันต์มาวางที่ตำแหน่ง A (ทางขวาของ $Q$ ห่าง $d$) ต้องทำงานอย่างน้อยเท่าใด
รูป: P-2016-charges.png
รูปจำเป็น: ใช่
ตัวเลือก A: $\frac{kq}{\sqrt{2}\,d}(\sqrt{2}Q + 2q)$
ตัวเลือก B: $\frac{kq}{\sqrt{2}\,d}(Q + q + \sqrt{2}q)$
ตัวเลือก C: $\frac{kq}{d}(Q + q)$
ตัวเลือก D: $\frac{kq}{2d}(\sqrt{2}Q + 2q)$
ตัวเลือก E: $\frac{kq}{2d}(2Q + q + \sqrt{2}q)$
คำตอบ: E
เฉลย: $W = qV_A$. ศักย์ที่ A: จาก $Q$ ระยะ $d$, จาก $q$ ซ้ายระยะ $2d$, จาก $q$ บนระยะ $\sqrt{2}d$ → $V_A = \frac{kQ}{d} + \frac{kq}{2d} + \frac{kq}{\sqrt{2}d} = \frac{k}{2d}(2Q + q + \sqrt{2}q)$ → $W = \frac{kq}{2d}(2Q + q + \sqrt{2}q)$
trap: ตอบ C — รวมประจุแบบเวกเตอร์ (สนามไฟฟ้า) แทนแบบสเกลาร์ (ศักย์ไฟฟ้า) หรือลืมประจุตัวไกล #พลาด/นิยาม
