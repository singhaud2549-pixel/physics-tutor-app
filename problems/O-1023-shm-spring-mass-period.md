# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1023
หัวข้อ: การเคลื่อนที่ฮาร์มอนิก (SHM)
หัวข้อย่อย: คาบการแกว่งของระบบมวล-สปริง (ขึ้นกับมวล ต่างจากลูกตุ้มอย่างง่าย)
ระดับความยาก: 3
โจทย์: มวล $0.5$ kg ติดปลายสปริงเส้นหนึ่งบนพื้นราบลื่น แกว่งในแนวราบด้วยคาบ $1.2$ s ถ้าเปลี่ยนมวลที่ติดปลายสปริงเป็น $2.0$ kg (ใช้สปริงเส้นเดิม ค่านิจสปริงเท่าเดิม) คาบการแกว่งใหม่จะเป็นเท่าใด (หน่วยวินาที)
ตัวเลือก A: 2.4 s
ตัวเลือก B: 1.2 s
ตัวเลือก C: 4.8 s
ตัวเลือก D: 0.6 s
ตัวเลือก E: 3.0 s
คำตอบ: A
เฉลย: คาบการแกว่งของระบบมวล-สปริงคือ $T=2\pi\sqrt{m/k}$ ซึ่ง**ขึ้นกับมวล** $m$ (ต่างจากลูกตุ้มอย่างง่ายที่คาบไม่ขึ้นกับมวลเลย) เนื่องจากค่านิจสปริง $k$ ไม่เปลี่ยนแปลง อัตราส่วนของคาบทั้งสองกรณีคือ $\dfrac{T_2}{T_1}=\sqrt{\dfrac{m_2}{m_1}}$. แทนค่า: $T_2 = T_1\sqrt{\dfrac{m_2}{m_1}} = 1.2\sqrt{\dfrac{2.0}{0.5}} = 1.2\sqrt{4} = 1.2\times2=2.4$ s
trap: ตอบ 1.2 s — จำเนื้อหาบทลูกตุ้มอย่างง่ายมาผิดบริบท (คาบของลูกตุ้มอย่างง่ายไม่ขึ้นกับมวล ขึ้นกับความยาวเชือกกับ $g$ เท่านั้น) แล้วสรุปผิดว่าคาบของระบบมวล-สปริงก็ไม่ขึ้นกับมวลเช่นกัน ทั้งที่จริงแล้วการเพิ่มมวลของระบบมวล-สปริงทำให้คาบเพิ่มขึ้นเสมอ (ความถี่ลดลง) #พลาด/เงื่อนไข #trap/80
trap: ตอบ 4.8 s — ลืมถอดรากที่สองในสูตรอัตราส่วนคาบ ใช้อัตราส่วนมวลตรงๆ แทนรากที่สองของอัตราส่วนมวล ($T_2=T_1\times(m_2/m_1)=1.2\times4=4.8$) ทั้งที่คาบแปรผันตามรากที่สองของมวล ไม่ใช่แปรผันตรงกับมวลโดยตรง #พลาด/พีชคณิต
trap: ตอบ 0.6 s — สลับอัตราส่วนมวลกลับด้าน ใช้ $T_2=T_1\sqrt{m_1/m_2}=1.2\sqrt{0.25}=0.6$ s แทนที่จะเป็น $\sqrt{m_2/m_1}$ (มวลเพิ่มขึ้นต้องทำให้คาบเพิ่มขึ้น ไม่ใช่ลดลง) #พลาด/สูตรผิด
trap: ตอบ 3.0 s — คำนวณรากที่สองผิดพลาด ($\sqrt4$ ควรเท่ากับ 2 พอดี แต่คำนวณผิดเป็น 2.5) แล้วคูณ $1.2\times2.5=3.0$ s ซึ่งเป็นความผิดพลาดทางคณิตศาสตร์ล้วนๆ ไม่ใช่ความเข้าใจผิดเชิงมโนทัศน์ #พลาด/พีชคณิต
