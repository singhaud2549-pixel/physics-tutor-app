# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1016
หัวข้อ: แรงและกฎนิวตัน
หัวข้อย่อย: กล่องสองใบวางซ้อนกัน แรงเสียดทานสถิตที่ปรับตัวตามที่จำเป็น (ไม่ใช่ค่าสูงสุดเสมอ)
ระดับความยาก: 4
โจทย์: กล่อง A มวล $5$ kg วางอยู่บนกล่อง B มวล $10$ kg ซึ่งวางอยู่บนพื้นราบที่ไม่มีแรงเสียดทานระหว่างกล่อง B กับพื้น มีแรงลัพธ์ในแนวราบขนาด $24$ N กระทำที่กล่อง B (ดึงกล่อง B ในแนวราบ) ทำให้กล่องทั้งสองเคลื่อนที่ไปด้วยกันโดยไม่ไถลสัมพัทธ์กัน สัมประสิทธิ์แรงเสียดทานสถิตสูงสุดระหว่างผิวสัมผัสของกล่อง A และ B คือ $\mu_s=0.3$ (กำหนด $g=10$ m/s$^2$) จงหาขนาดของแรงเสียดทานสถิตที่กระทำกับกล่อง A ขณะนี้ (หน่วยนิวตัน)
หน่วย: นิวตัน (N)
คำตอบ: 8
คลาดเคลื่อน: 0.2
เฉลย: เนื่องจากกล่อง A ไม่มีแรงภายนอกกระทำโดยตรง (แรง 24 N กระทำที่กล่อง B เท่านั้น) แรงเดียวที่ทำให้กล่อง A เคลื่อนที่ไปพร้อมกับกล่อง B ได้คือแรงเสียดทานสถิตจากผิวบนของกล่อง B ก่อนอื่นหาความเร่งของระบบทั้งหมด (เคลื่อนที่ไปด้วยกัน จึงมีความเร่งเท่ากัน และพื้นใต้ B ไม่มีแรงเสียดทาน): $a = \dfrac{F}{m_A+m_B} = \dfrac{24}{5+10} = \dfrac{24}{15} = 1.6$ m/s$^2$. พิจารณากล่อง A เพียงก้อนเดียว แรงเสียดทานสถิต $f$ ที่กระทำกับมันคือแรงลัพธ์เพียงแรงเดียวในแนวราบที่ทำให้มันมีความเร่งเท่ากับระบบ: $f = m_A \times a = 5\times1.6 = 8$ N. ตรวจสอบว่าค่านี้เป็นไปได้จริงหรือไม่ (แรงเสียดทานสถิตที่ต้องการต้องไม่เกินค่าสูงสุดที่ผิวสัมผัสรับได้): $f_{max}=\mu_s m_A g = 0.3\times5\times10=15$ N เนื่องจาก $f=8\text{ N} \le f_{max}=15\text{ N}$ แสดงว่ากล่องทั้งสองเคลื่อนที่ไปด้วยกันได้จริงโดยไม่ไถล (สอดคล้องกับที่โจทย์กำหนด) ดังนั้นแรงเสียดทานสถิตที่กระทำกับกล่อง A คือ $8$ N
trap: ตอบ 15 N — เข้าใจผิดว่าแรงเสียดทานสถิตที่กระทำต้องมีค่าเท่ากับค่าสูงสุดเสมอ ($f=\mu_s N$) ทั้งที่จริงแล้วแรงเสียดทานสถิตเป็นแรง "ปรับตัวได้" ตามขนาดที่จำเป็นเพื่อรักษาสภาพไม่ไถล (ไม่เกินค่าสูงสุด) ไม่ใช่ค่าคงที่สูงสุดตลอดเวลา #พลาด/เงื่อนไข #trap/18
trap: ตอบ 24 N — เข้าใจผิดว่าแรง $F$ ทั้งหมดที่ดึงกล่อง B ถูกส่งผ่านไปยังกล่อง A โดยตรงทั้งหมด ลืมว่าแรง F กระทำที่กล่อง B เท่านั้น กล่อง A ได้รับแรงผ่านแรงเสียดทานที่ผิวสัมผัสเพียงอย่างเดียว ซึ่งน้อยกว่าแรง F ทั้งหมดมาก #พลาด/ระบบ #trap/161
trap: ตอบ 12 N — คำนวณความเร่งของระบบผิดพลาด โดยใช้เฉพาะมวลของกล่อง B ในการหาความเร่ง ($a=F/m_B=24/10=2.4$ m/s$^2$) เพราะคิดว่าแรง F กระทำกับ B เท่านั้นจึงควรใช้มวลของ B อย่างเดียวหาความเร่ง แล้วนำไปคูณกับมวลของ A ได้ $f=m_A\times2.4=12$ N ทั้งที่ความเร่งของระบบต้องคำนวณจากมวลรวมทั้งหมด ($m_A+m_B$) เพราะกล่องทั้งสองเคลื่อนที่ไปด้วยกัน #พลาด/ระบบ #trap/161
