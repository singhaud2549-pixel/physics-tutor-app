โจทย์: จากวงจรในรูป แบตเตอรี่ให้แรงเคลื่อนไฟฟ้า 20 V (ไม่คิดความต้านทานภายใน) ต่ออนุกรมกับ $R_1=4~\Omega$ ไปยังจุด A จากจุด A มีสองเส้นทาง: เส้นทางหนึ่งผ่าน $R_2=6~\Omega$ กลับไปยังขั้วลบของแบตเตอรี่ (จุด B) อีกเส้นทางผ่าน $R_3=2~\Omega$ ต่ออนุกรมกับตัวเก็บประจุ C แล้วไปบรรจบที่จุด B เช่นกัน เมื่อวงจรเข้าสู่สภาวะคงตัวแล้ว (กระแสคงที่ ไม่เปลี่ยนแปลงตามเวลา) แรงดันตกคร่อมตัวเก็บประจุ C มีค่าเท่าใด

เฉลย: ที่สภาวะคงตัว ตัวเก็บประจุที่ชาร์จเต็มแล้วทำหน้าที่เสมือน "วงจรเปิด" (ไม่มีกระแสไหลผ่านกิ่งที่มี C และ $R_3$ อีกต่อไป) ดังนั้นกระแสทั้งหมดไหลผ่านเฉพาะเส้นทาง $R_1$ กับ $R_2$ เท่านั้น: $I = \dfrac{V}{R_1+R_2} = \dfrac{20}{4+6} = 2$ A. เนื่องจากไม่มีกระแสไหลผ่าน $R_3$ จึงไม่มีแรงดันตกคร่อม $R_3$ ($V_{R_3}=IR_3=0$) ดังนั้นแรงดันที่จุด A เทียบกับจุด B ผ่านเส้นทาง $R_3$-C จึงเท่ากับแรงดันตกคร่อม $R_2$ ทั้งหมด: $V_C = V_{R_2} = I\times R_2 = 2\times6 = 12$ V
trap: ตอบ A (8 V) — สลับไปตอบแรงดันตกคร่อม $R_1$ ($I\times R_1=2\times4=8$ V) แทนที่จะเป็นแรงดันคร่อม $R_2$ ซึ่งเป็นกิ่งที่ขนานกับเส้นทางตัวเก็บประจุ #พลาด/อ่านโจทย์
trap: ตอบ B (20 V) — คิดว่าเมื่อกระแสไม่ไหลผ่านกิ่งที่มี C แรงดันทั้งหมดจากแบตเตอรี่จะตกคร่อม C ทั้งก้อน ลืมว่า $R_1$ และ $R_2$ ยังมีกระแสไหลผ่านและมีแรงดันตกคร่อมอยู่จริง #พลาด/เงื่อนไข #trap/38
trap: ตอบ C (0 V) — เข้าใจผิดว่าตัวเก็บประจุที่สภาวะคงตัวเป็นเสมือนวงจรลัด (short circuit) เหมือนกับตัวเหนี่ยวนำที่สภาวะคงตัว ทั้งที่จริงกฎของตัวเก็บประจุตรงข้ามกัน คือเป็นวงจรเปิด #พลาด/นิยาม #trap/38
trap: ตอบ E (10 V) — เข้าใจผิดว่าทั้งวงจรต่ออนุกรมกันหมด (รวม $R_3$ เข้าไปในเส้นทางกระแสหลักด้วย) ทำให้คำนวณกระแสรวมผิดพลาดแล้วส่งผลต่อแรงดันคร่อม $R_2$ ที่คำนวณได้ #พลาด/ระบบ
