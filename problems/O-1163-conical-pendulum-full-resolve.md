# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1163
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: ลูกตุ้มกรวยแตกแรงสองแกน
ระดับความยาก: 3
โจทย์: ลูกตุ้มมวล $0.4$ kg ผูกติดกับเชือกเบายาว $0.50$ m แล้วแกว่งเป็นวงกลมสม่ำเสมอในระนาบระดับ (ลูกตุ้มกรวย) ด้วยอัตราเร็ว $1.5$ m/s ให้วาดแผนภาพแรง (FBD) ที่ลูกตุ้มแล้วหาว่าแรงตึงในเส้นเชือกมีค่าเท่าใด (กำหนด $g=10$ m/s$^2$)
รูป: O-1163.png
รูปจำเป็น: ไม่
หน่วย: นิวตัน (N)
คำตอบ: 5
คลาดเคลื่อน:
เฉลย: วาด FBD ที่ลูกตุ้มมีแรงสองแรงคือแรงตึง $T$ (เอียงตามเชือก) กับน้ำหนัก $mg$ (ดิ่งลง) แตก $T$ เป็นสองแกน แกนดิ่งสมดุล $T\cos\theta = mg = 4$ N ส่วนแนวระดับ $T\sin\theta = mv^2/r$ โดย $r = L\sin\theta$ แทนค่า $T\sin\theta = (0.4)(1.5)^2/(0.50\sin\theta)$ คูณ $\sin\theta$ ทั้งสองข้างได้ $T\sin^2\theta = 1.8$ รวมกับ $(T\cos\theta)^2 = 16$ ใช้เอกลักษณ์ $\sin^2\theta + \cos^2\theta = 1$ ได้ $T^2 = 1.8T + 16$ แก้สมการได้ $T = 5$ N (อีกวิธีที่ตรงกว่า: $T = \sqrt{(T\sin\theta)^2 + (T\cos\theta)^2}$ แต่ $T\sin\theta = mv^2/r$ ยังติด $r$ ให้เดาว่าเป็นมุม $37^\circ$ ($\sin = 0.6$, $\cos = 0.8$) แล้วตรวจกลับ $r = 0.50 \times 0.6 = 0.30$ m, $mv^2/r = (0.4)(2.25)/0.30 = 3$ N, $T = \sqrt{3^2 + 4^2} = 5$ N และ $5\cos 37^\circ = 4 = mg$ ลงตัวพอดี ยืนยันว่า $\theta = 37^\circ$ จริง)
trap: ตอบ 4 — ตอบแค่น้ำหนัก $mg = 4$ N (แตกแค่แกนดิ่งแล้วหยุด ลืมว่าต้องมีองค์ประกอบแนวระดับมาทำหน้าที่เป็นแรงสู่ศูนย์กลางด้วย) #พลาด/แผนภาพแรง
trap: ตอบ 3 — ตอบแค่แรงสู่ศูนย์กลาง $mv^2/r = 3$ N (คำนวณแกนระดับได้แล้วลืมรวมน้ำหนักในแกนดิ่ง คิดว่าแรงตึงเท่ากับแรงสู่ศูนย์กลางอย่างเดียว) #พลาด/แผนภาพแรง
trap: ตอบ 7 — เอาน้ำหนักบวกกับแรงสู่ศูนย์กลางตรงๆ $T = mg + mv^2/r = 4 + 3 = 7$ N (ลืมว่าสองแรงนี้ตั้งฉากกัน ต้องรวมแบบเวกเตอร์ด้วยทฤษฎีบทพีทาโกรัส ไม่ใช่บวกเลขตรงๆ) #พลาด/เวกเตอร์
trap: ตอบ 1 — เอาน้ำหนักลบกับแรงสู่ศูนย์กลาง $T = |mg - mv^2/r| = |4 - 3| = 1$ N (ลืมว่าสองแรงนี้ตั้งฉากกัน ไม่ได้อยู่บนเส้นตรงเดียวกันจึงหักลบกันแบบนี้ไม่ได้) #พลาด/เวกเตอร์
