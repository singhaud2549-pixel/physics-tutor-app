# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1021
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: แรงตึงเชือกที่จุดต่ำสุดของวงกลมแนวดิ่ง (ต้องรวมทั้งน้ำหนักและแรงสู่ศูนย์กลาง)
ระดับความยาก: 3
โจทย์: วัตถุมวล $2$ kg ผูกติดกับเชือกเบายาว $1.5$ m แล้วแกว่งเป็นวงกลมในระนาบดิ่ง ขณะวัตถุอยู่ที่ตำแหน่งต่ำสุดของวงกลม อัตราเร็วของวัตถุคือ $6$ m/s จงหาแรงตึงเชือกที่ตำแหน่งนี้ (หน่วยนิวตัน กำหนด $g=10$ m/s$^2$)
ตัวเลือก A: 20 N
ตัวเลือก B: 48 N
ตัวเลือก C: 68 N
ตัวเลือก D: 44 N
ตัวเลือก E: 28 N
คำตอบ: C
เฉลย: ที่ตำแหน่งต่ำสุดของวงกลมแนวดิ่ง วัตถุยังคงเคลื่อนที่เป็นวงกลมอยู่ (ไม่ได้อยู่นิ่ง) จึงต้องมีแรงลัพธ์ในแนวดิ่งพุ่งเข้าหาศูนย์กลางวงกลม (พุ่งขึ้น) ทำหน้าที่เป็นแรงสู่ศูนย์กลาง แรงในแนวดิ่งที่กระทำต่อวัตถุมีสองแรง คือแรงตึงเชือก $T$ (พุ่งขึ้นเข้าหาศูนย์กลาง) และน้ำหนัก $mg$ (พุ่งลง) ให้ทิศพุ่งเข้าศูนย์กลาง (ขึ้น) เป็นบวก: $T - mg = \dfrac{mv^2}{r}$. แทนค่า: $T = mg + \dfrac{mv^2}{r} = (2)(10) + \dfrac{(2)(6)^2}{1.5} = 20 + \dfrac{72}{1.5} = 20+48=68$ N
trap: ตอบ 20 N — เข้าใจผิดว่าที่ตำแหน่งต่ำสุด วัตถุอยู่ในสภาวะสมดุลแรงพอดี (เหมือนวัตถุห้อยนิ่ง) จึงตอบเพียงน้ำหนัก $mg=20$ N โดยลืมว่าวัตถุยังเคลื่อนที่เป็นวงกลมอยู่ ต้องมีแรงลัพธ์สุทธิพุ่งเข้าศูนย์กลางไม่เท่ากับศูนย์ ($T-mg=mv^2/r \ne 0$) #พลาด/แผนภาพแรง
trap: ตอบ 48 N — ลืมรวมน้ำหนัก $mg$ เข้ากับแรงตึงเชือก คิดว่าแรงตึงเชือกทำหน้าที่เป็นแรงสู่ศูนย์กลางเพียงอย่างเดียว ($T=mv^2/r$) โดยไม่ได้บวกน้ำหนักที่กระทำในทิศตรงข้ามกับแรงสู่ศูนย์กลางที่จุดต่ำสุด #พลาด/แผนภาพแรง
trap: ตอบ 44 N — เข้าใจผิดว่าความยาวเชือกที่ให้มาคือ "เส้นผ่านศูนย์กลาง" ของวงกลม ไม่ใช่รัศมี จึงใช้ $r=2\times1.5=3$ m แทนที่จะเป็น $r=1.5$ m ตรงๆ (ความยาวเชือกที่ผูกวัตถุแกว่งเป็นวงกลม คือรัศมีของวงกลมโดยตรงเสมอ) #พลาด/อ่านโจทย์
trap: ตอบ 28 N — คำนวณแรงสู่ศูนย์กลางผิดพลาดโดยลืมยกกำลังสองความเร็ว ใช้ $mv/r$ แทน $mv^2/r$ ได้ $T=mg+mv/r=20+(2)(6)/1.5=20+8=28$ N ซึ่งผิดสูตร #พลาด/สูตรผิด
