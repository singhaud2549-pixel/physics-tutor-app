# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2017
หัวข้อ: ไฟฟ้าสถิต
หัวข้อย่อย: งานของสนามไฟฟ้า
ระดับความยาก: 3
โจทย์: จุด A และ B ห่างกัน $L$ ในบริเวณสนามไฟฟ้าสม่ำเสมอขนาด $E$ ทิศทำมุม $\theta$ กับแนว AB ดังรูป มีแรง $F$ ลากจุดประจุ $q$ มวล $m$ จากหยุดนิ่งที่ B ไปยัง A พบว่าประจุมีอัตราเร็ว $v$ งานที่แรง $F$ ทำเท่ากับข้อใด
รูป: P-2017-field.png
รูปจำเป็น: ใช่
ตัวเลือก A: $-qEL - \frac{mv^2}{2}$
ตัวเลือก B: $+qEL\cos\theta - \frac{mv^2}{2}$
ตัวเลือก C: $-qEL\cos\theta + \frac{mv^2}{2}$
ตัวเลือก D: $+qEL\cos\theta + \frac{mv^2}{2}$
ตัวเลือก E: $-qEL\sin\theta + \frac{mv^2}{2}$
คำตอบ: D
เฉลย: ทฤษฎีบทงาน-พลังงาน $W_F + W_E = \Delta KE$. เคลื่อนที่ B→A ทิศตรงข้าม AB ทำมุม $180^\circ-\theta$ กับสนาม → $W_E = qEL\cos(180^\circ-\theta) = -qEL\cos\theta$. ดังนั้น $W_F - qEL\cos\theta = \frac{1}{2}mv^2$ → $W_F = +qEL\cos\theta + \frac{mv^2}{2}$
trap: ตอบ C — ลืมกลับทิศการกระจัดเทียบทิศสนาม ทำให้คิดงานสนามไฟฟ้าเป็นบวก #พลาด/ทิศ
