# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2032
หัวข้อ: ฟิสิกส์อะตอม/ควอนตัม
หัวข้อย่อย: แบบจำลองอะตอมของโบร์
ระดับความยาก: 3
โจทย์: ตามแบบจำลองอะตอมของโบร์ อิเล็กตรอนที่เปลี่ยนระดับพลังงานจากสถานะกระตุ้นที่ 3 ไปยังสถานะพื้น จะปล่อยโฟตอนที่มีความยาวคลื่นเป็นกี่เท่าของโฟตอนจากการเปลี่ยนจากสถานะกระตุ้นที่ 1 ไปยังสถานะพื้น
หน่วย: เท่า
คำตอบ: 0.8
เฉลย: สถานะพื้น n=1, กระตุ้นที่ 1 คือ n=2, กระตุ้นที่ 3 คือ n=4. λ แปรผกผันกับ ΔE. ΔE(4→1) = 13.6(1−1/16) = 13.6·15/16 ; ΔE(2→1) = 13.6(1−1/4) = 13.6·3/4. λ(4→1)/λ(2→1) = ΔE(2→1)/ΔE(4→1) = (3/4)/(15/16) = 48/60 = 0.8
trap: ตอบ 1.25 — ตั้งสัดส่วน λ กลับด้านกับสัดส่วนพลังงาน
trap: ตอบ 0.88 — เข้าใจผิดว่าสถานะกระตุ้นที่ 3 คือ n=3 (จริง ๆ คือ n=4)
