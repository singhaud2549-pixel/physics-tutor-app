# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1015
หัวข้อ: แรงและกฎนิวตัน
หัวข้อย่อย: น้ำหนักปรากฏบนตาชั่งสปริงในลิฟต์ที่กำลังเร่งขึ้น
ระดับความยาก: 3
โจทย์: ชายคนหนึ่งมวล $60$ kg ยืนอยู่บนตาชั่งสปริงภายในลิฟต์ ขณะลิฟต์กำลังเคลื่อนที่ขึ้นด้วยความเร่งคงที่ $2$ m/s$^2$ ตาชั่งจะอ่านค่าน้ำหนักปรากฏของชายคนนี้เท่าใด (หน่วยนิวตัน กำหนด $g=10$ m/s$^2$)
ตัวเลือก A: 480 N
ตัวเลือก B: 600 N
ตัวเลือก C: 720 N
ตัวเลือก D: 120 N
ตัวเลือก E: 840 N
คำตอบ: C
เฉลย: ตาชั่งสปริงวัดแรงปกติ $N$ ที่พื้นตาชั่งกระทำต่อชายคนนั้น (ซึ่งเท่ากับแรงที่ชายคนนั้นกดลงบนตาชั่งตามกฎข้อ 3 ของนิวตัน) ให้ทิศขึ้นเป็นบวก เขียนกฎข้อ 2 ของนิวตันสำหรับชายคนนั้น: $N - mg = ma$ (เพราะลิฟต์กำลังเร่งขึ้น ความเร่งสุทธิของชายคนนั้นมีทิศขึ้นเท่ากับ $a=2$ m/s$^2$) ดังนั้น $N = m(g+a) = 60(10+2) = 60\times12 = 720$ N. (น้ำหนักจริงของชายคนนี้คือ $mg=600$ N ไม่เปลี่ยนแปลง แต่ตาชั่งอ่านค่า "น้ำหนักปรากฏ" ซึ่งมากกว่าน้ำหนักจริงเพราะลิฟต์กำลังเร่งขึ้น)
trap: ตอบ 480 N — สลับทิศของความเร่ง เข้าใจผิดว่าเมื่อลิฟต์ "เคลื่อนที่ขึ้น" แรงปกติต้องน้อยกว่าน้ำหนักจริงเสมอ (เหมือนกรณีเร่งลง/ชะลอขึ้น) จึงใช้ $N=m(g-a)=480$ N แทนที่จะเป็น $m(g+a)$ ทั้งที่โจทย์ระบุชัดว่าลิฟต์ "กำลังเร่งขึ้น" (ความเร่งพุ่งขึ้นเช่นเดียวกับความเร็ว)
trap: ตอบ 600 N — ตอบน้ำหนักจริง $mg$ เฉยๆ โดยไม่คิดผลของความเร่งเลย เหมือนคิดว่าลิฟต์เคลื่อนที่ด้วยความเร็วคงที่ (a=0) ทั้งที่โจทย์ให้ความเร่ง 2 m/s² มาชัดเจน
trap: ตอบ 120 N — เข้าใจผิดว่าตาชั่งอ่านค่าแรงลัพธ์ ($F_{net}=ma$) เพียงอย่างเดียว ลืมว่าแรงปกติที่ตาชั่งวัดได้ต้องรวมทั้งน้ำหนักจริง $mg$ และแรงที่ทำให้เกิดความเร่งเพิ่มเข้าไปด้วย ($N=mg+ma$ ไม่ใช่แค่ $ma$)
trap: ตอบ 840 N — คำนวณผิดพลาดทางคณิตศาสตร์โดยเผลอคูณความเร่งซ้ำสองเท่า ได้ $N=m(g+2a)=60\times14=840$ N ซึ่งไม่ตรงกับสมการที่ถูกต้อง
