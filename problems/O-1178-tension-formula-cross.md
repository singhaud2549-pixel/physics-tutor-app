# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1178
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: สูตรแรงตึงรูปตัวแปร
ระดับความยาก: 4
โจทย์: วัตถุมวล $m$ ผูกเชือกเบายาว $r$ แกว่งเป็นวงกลมในระนาบดิ่ง ขณะที่เชือกทำมุม $\phi$ กับแนวดิ่งโดยวัดจากจุดต่ำสุดของวงกลม (ที่จุดต่ำสุด $\phi = 0$) วัตถุนั้นมีอัตราเร็ว $v$ ข้อใดเขียนแรงตึงเชือก $T$ ในรูปของ $m$, $g$, $v$, $r$ และ $\phi$ ได้ถูกต้อง
ตัวเลือก A: $T = \dfrac{mv^2}{r} + mg\cos\phi$
ตัวเลือก B: $T = \dfrac{mv^2}{r} - mg\cos\phi$
ตัวเลือก C: $T = mv^2r + mg\cos\phi$
ตัวเลือก D: $T = mv^2r - mg\cos\phi$
ตัวเลือก E: $T = \dfrac{mv^2}{r} + mg\sin\phi$
คำตอบ: A
เฉลย: แตกน้ำหนัก $mg$ (ชี้ลง) เข้าแนวรัศมี: องค์ประกอบตามแนวเชือก (ชี้ออกจากศูนย์กลาง) มีขนาด $mg\cos\phi$ ส่วนแรงตึง $T$ ชี้เข้าศูนย์กลาง ให้ทิศเข้าศูนย์กลางเป็นบวก: $T - mg\cos\phi = \dfrac{mv^2}{r}$ จึงได้ $T = \dfrac{mv^2}{r} + mg\cos\phi$ (ตรวจซ้ำด้วยกรณีพิเศษ: ที่จุดต่ำสุด $\phi = 0$ ได้ $T = mv^2/r + mg$ ถูกต้องตามสูตรจุดต่ำสุด และที่จุดสูงสุด $\phi = 180°$ ได้ $\cos\phi = -1$ เป็น $T = mv^2/r - mg$ ถูกต้องตามสูตรจุดสูงสุด)
trap: ตอบ B — เครื่องหมายของเทอมน้ำหนักสลับขั้ว ($-$ แทน $+$) มาจากลืมแตกแรงแล้วเอา $T + mg\cos\phi = mv^2/r$ ทั้งที่น้ำหนักมีองค์ประกอบออกจากศูนย์กลาง ต้องย้ายข้างเป็นบวก ตรวจด้วยจุดต่ำสุดจะได้ $T = mv^2/r - mg$ ซึ่งผิด #พลาด/แผนภาพแรง
trap: ตอบ C — วาง $r$ ผิดที่ (คูณแทนหาร: $mv^2r$) มาจากจำสูตรแรงสู่ศูนย์กลางสลับกับสูตรอื่น ตรวจมิติก็ตกแล้ว ($mv^2r$ มีหน่วย kg·m$^3$/s$^2$ ไม่ใช่นิวตัน) #พลาด/สูตรผิด
trap: ตอบ D — ผิดพร้อมกันสองแกน (เครื่องหมายลบ แถม $r$ อยู่ข้างบน) เป็นทางคิดผิดซ้อนของ B กับ C เหมาะดักเด็กที่เดาจากความคุ้นสูตรโดยไม่วิเคราะห์แรง #พลาด/แผนภาพแรง
trap: ตอบ E — ใช้ฟังก์ชันมุมผิด ($\sin\phi$ แทน $\cos\phi$) มาจากแตกองค์ประกอบน้ำหนักเทียบมุมผิดด้าน ตรวจด้วยจุดต่ำสุด $\phi=0$ จะได้ $T = mv^2/r$ ซึ่งขาดเทอม $mg$ ไปทันที #พลาด/ตรีโกณ
