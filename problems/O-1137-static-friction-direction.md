# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้
id: O-1137
หัวข้อ: แรงและกฎนิวตัน
ระดับชั้น: ม.6
หัวข้อย่อย: แรงเสียดทานสถิตกับทิศทาง
ระดับความยาก: 4
โจทย์: มวล 4 kg วางบนพื้นเอียงทำมุม $37°$ กับแนวราบ มีเชือกผูกมวลนี้พาดผ่านรอกที่ยอดพื้นเอียง ปลายอีกข้างแขวนมวล 3 kg สัมประสิทธิ์แรงเสียดทานสถิตระหว่างมวลกับพื้นเอียงเท่ากับ 0.3 ปรากฏว่าระบบอยู่นิ่งไม่ขยับ (กำหนด $\sin37°=0.6$, $\cos37°=0.8$, $g=10$ m/s$^2$) จงหาขนาดของแรงเสียดทานสถิตที่กระทำต่อมวลบนพื้นเอียง (หน่วย N)
หน่วย: N
คำตอบ: 6
คลาดเคลื่อน:
เฉลย: ตรวจแนวโน้มก่อน: น้ำหนักมวลแขวน $3(10)=30$ N มากกว่าองค์ประกอบตามพื้นเอียง $4(10)(0.6)=24$ N มวลบนพื้นเอียงจึงมีแนวโน้มถูกดึงขึ้น แรงเสียดทานสถิตจึงชี้ลงตามพื้นเอียง ขนาดพอดีสมดุล: $f=30-24=6$ N (ตรวจว่าไม่เกินค่าสูงสุด $\mu_s N=0.3(4)(10)(0.8)=9.6$ N จึงนิ่งจริง ไม่ใช่แรงเสียดทานสูงสุด)
trap: ตอบ 9.6 — เอาค่าสูงสุด $\mu_s N$ มาตอบเลย ลืมว่าแรงเสียดทานสถิตมีค่าเท่าที่จำเป็นให้สมดุล ไม่ใช่สูงสุดเสมอ #พลาด/นิยาม
