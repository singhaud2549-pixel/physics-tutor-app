# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2007
หัวข้อ: การเคลื่อนที่ฮาร์มอนิก (SHM)
หัวข้อย่อย: สมการการกระจัดและความเร็ว
ระดับความยาก: 4
โจทย์: วัตถุมวล m ผูกติดกับสปริงเบาบนพื้นราบลื่น สั่นกลับไปกลับมารอบจุดสมดุลด้วยความถี่เชิงมุม 2.0 rad/s แอมพลิจูด 1.2 m ที่เวลา t = 0 วัตถุมีการกระจัด +0.6 m และกำลังเคลื่อนที่ทิศ +x จงหาอัตราเร็วของวัตถุ (m/s) ที่เวลา t = π/12 วินาที
ตัวเลือก A: 2.4
ตัวเลือก B: 2.0
ตัวเลือก C: 1.8
ตัวเลือก D: 1.2
ตัวเลือก E: 0.6
คำตอบ: D
เฉลย: x(t) = A sin(ωt + φ); ที่ t=0: 0.6 = 1.2 sin(φ) → φ = π/6 (เลือก π/6 เพราะทิศ +x). v(t) = Aω cos(ωt + φ) = 2.4 cos(2t + π/6). ที่ t = π/12: เฟส = π/6 + π/6 = π/3 → v = 2.4 cos(π/3) = 2.4×0.5 = 1.2 m/s
trap: ตอบ A — เอาความเร็วสูงสุด v_max = Aω = 2.4 มาตอบ ลืมคูณ cos ของเฟส
trap: ตอบ E — ใช้ sine แทน cosine ในการหาความเร็ว หรือคิดเฟสตั้งต้นผิด
