# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1170
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: เชือกหย่อนที่มุมวิกฤต
ระดับความยาก: 3
โจทย์: ลูกตุ้มมวล $0.5$ kg ผูกเชือกเบายาว $1.4$ m แกว่งขึ้นจากจุดต่ำสุดของวงกลมแนวดิ่งด้วยอัตราเร็วต้น $7$ m/s ที่จุดต่ำสุดพอดี ขณะลูกตุ้มเคลื่อนขึ้นไป เชือกจะหย่อน (แรงตึงเชือกเป็นศูนย์พอดี) เมื่อเชือกทำมุม $\theta$ กับแนวดิ่ง (วัดจากตำแหน่งต่ำสุด ดังรูป) จงหามุม $\theta$ นี้ (กำหนด $g=10$ m/s$^2$)
ตัวเลือก A: 60°
ตัวเลือก B: 90°
ตัวเลือก C: 120°
ตัวเลือก D: 139° (ประมาณ)
ตัวเลือก E: 180°
รูป: O-1170.png
รูปจำเป็น: ไม่
คำตอบ: C
เฉลย: ให้ $\theta$ วัดจากจุดต่ำสุด ความสูงที่ขึ้นไปคือ $h = L(1-\cos\theta)$ จากงาน-พลังงาน (แรงตึงไม่ทำงานเพราะตั้งฉากการเคลื่อนที่ตลอด): $v^2 = v_0^2 - 2gL(1-\cos\theta)$. แตกน้ำหนักเข้าทิศรัศมี (ทิศเข้าศูนย์กลาง): องค์ประกอบน้ำหนักชี้ออกจากศูนย์กลางขนาด $mg\cos\theta$ ส่วนแรงตึง $T$ ชี้เข้าศูนย์กลาง ได้ $T - mg\cos\theta\cdot(-1)$…จัดรูปให้ถูกคือ $T = \dfrac{mv^2}{L} + mg\cos\theta$. ตั้งเงื่อนไขเชือกหย่อน $T=0$: $\dfrac{m(v_0^2-2gL+2gL\cos\theta)}{L} + mg\cos\theta = 0$ หารด้วย $m$ แล้วจัดรูป: $\dfrac{v_0^2}{L} - 2g + 3g\cos\theta = 0$ ได้ $\cos\theta = \dfrac{2}{3} - \dfrac{v_0^2}{3gL} = \dfrac{2}{3} - \dfrac{49}{3(10)(1.4)} = \dfrac{2}{3} - \dfrac{7}{6} = -\dfrac12$ ดังนั้น $\theta = 120°$ (ตรวจอีกวิธี: ที่ $\theta=120°$ ได้ $v^2 = 49 - 2(10)(1.4)(1.5) = 49-42 = 7$ แล้ว $T = (0.5)(7)/1.4 + (0.5)(10)(-0.5) = 2.5-2.5 = 0$ พอดี)
trap: ตอบ 60° — เครื่องหมายผิดตอนย้ายข้าง ได้ $\cos\theta = +\dfrac12$ (ลืมว่า $\cos\theta$ ต้องเป็นลบเพราะจุดหย่อนอยู่สูงกว่าระดับศูนย์กลาง) จึงตอบมุมแหลม $60°$ แทนมุมป้าน $120°$ #พลาด/พีชคณิต
trap: ตอบ 90° — เข้าใจผิดว่าเชือกจะหย่อนทันทีที่ลูกตุ้มขึ้นถึงระดับเดียวกับจุดหมุน เพราะคิดว่าองค์ประกอบน้ำหนักในแนวรัศมีเป็นศูนย์แล้ว $T$ ต้องเป็นศูนย์ด้วย โดยลืมว่า $T = mv^2/L + mg\cos\theta$ ที่ $\theta=90°$ ยังเหลือ $T = mv^2/L > 0$ #พลาด/เงื่อนไข
trap: ตอบ 139° (ประมาณ) — สับสนเงื่อนไขเชือกหย่อน ($T=0$) กับจุดกลับตัว ($v=0$) ใช้ $v_0^2 = 2gL(1-\cos\theta)$ ได้ $\cos\theta = 1 - 49/28 = -0.75$ จึงตอบ $\theta \approx 138.6°$ ทั้งที่จุดนั้นเชือกยังตึงอยู่ ($T = mg\cos\theta$ เป็นลบไม่ได้ จึงหย่อนก่อนถึงจุดนั้น) #พลาด/เงื่อนไข
trap: ตอบ 180° — เข้าใจผิดว่าเชือกจะหย่อนได้เฉพาะที่จุดสูงสุดของวงเท่านั้น (จำภาพจำจากเงื่อนไขครบวง $v=\sqrt{gR}$) โดยไม่ได้วิเคราะห์ว่าเชือกหย่อนตั้งแต่ $T=0$ ที่มุม $120°$ แล้ว #พลาด/เงื่อนไข
