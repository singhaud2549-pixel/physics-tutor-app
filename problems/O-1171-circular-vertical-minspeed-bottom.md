# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1171
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: ความเร็วต่ำสุดครบวงเชือก
ระดับความยาก: 3
โจทย์: นักกายกรรมควงลูกเหล็กมวล $1.5$ kg ด้วยเชือกเบายาว $2.0$ m เป็นวงกลมในระนาบดิ่ง จงหาอัตราเร็วต่ำสุดที่จุดต่ำสุดของวง ที่ทำให้ลูกเหล็กเคลื่อนที่ครบวงกลมได้พอดีโดยเชือกยังคงตึงตลอดเวลา (หน่วย m/s กำหนด $g=10$ m/s$^2$)
หน่วย: เมตรต่อวินาที (m/s)
คำตอบ: 10
คลาดเคลื่อน:
เฉลย: เงื่อนไขวิกฤตให้เชือกตึงตลอดวงคือที่จุดสูงสุดเชือกตึงพอดี ($T=0$) เหลือเพียงน้ำหนักเป็นแรงสู่ศูนย์กลาง: $mg = \dfrac{mv_{top}^2}{R}$ ได้ $v_{top}^2 = gR = (10)(2.0) = 20$. จากนั้นใช้การอนุรักษ์พลังงานกลจากจุดต่ำสุดถึงจุดสูงสุด (สูงขึ้น $2R = 4.0$ m): $\dfrac12mv_{bot}^2 = \dfrac12mv_{top}^2 + mg(2R)$ หารด้วย $m/2$ ได้ $v_{bot}^2 = v_{top}^2 + 4gR = gR + 4gR = 5gR = 5(10)(2.0) = 100$ ดังนั้น $v_{bot} = 10$ m/s (ตรวจอีกวิธี: พลังงานที่จุดต่ำสุด $\frac12(1.5)(100) = 75$ J เท่ากับจลน์ที่จุดสูงสุด $\frac12(1.5)(20) = 15$ J บวกศักย์ $mg(2R) = (1.5)(10)(4.0) = 60$ J รวม $15+60 = 75$ J พอดี และมวล $m$ ตัดกันทั้งสองขั้นจึงไม่ต้องใช้ค่า $1.5$ kg เลย)
trap: ตอบ 4.47 m/s (ประมาณ $\sqrt{20}$) — คำนวณ $v_{top}^2 = gR = 20$ ถูกต้อง แต่ตอบอัตราเร็วที่จุดสูงสุดเลย ลืมถามอัตราเร็วที่จุดต่ำสุดซึ่งต้องเผื่อพลังงานศักย์ $mg(2R)$ ด้วย #พลาด/อ่านโจทย์
trap: ตอบ 8.94 m/s (ประมาณ $\sqrt{80}$) — ใช้เงื่อนไขผิดว่าที่จุดสูงสุดความเร็วเป็นศูนย์ ($v_{top}=0$) แล้วใช้พลังงาน $v_{bot}^2 = 2g(2R) = 4gR = 80$ ลืมว่าถ้า $v_{top}=0$ เชือกจะหย่อนก่อนถึงจุดสูงสุด ต้องมี $v_{top}^2=gR$ #พลาด/เงื่อนไข
trap: ตอบ 6.32 m/s (ประมาณ $\sqrt{40}$) — ใช้ความสูงแค่ $R$ แทน $2R$ ได้ $v_{bot}^2 = v_{top}^2 + 2gR = 20+40 = 60$…หรือใช้ $v_{bot}^2 = 2gR = 40$ (คิดว่าขึ้นแค่หนึ่งรัศมี) ลืมว่าจากจุดต่ำสุดถึงจุดสูงสุดคือเส้นผ่านศูนย์กลาง $2R$ #พลาด/อ่านโจทย์
trap: ตอบ 15 m/s — เอามวล $1.5$ kg ไปคูณคำตอบ $10$ ทั้งที่มวลตัดกันหมดทั้งขั้นแรงสู่ศูนย์กลางและขั้นพลังงาน ข้อนี้ให้มวลมาหลอกโดยเฉพาะ #พลาด/อ่านโจทย์
