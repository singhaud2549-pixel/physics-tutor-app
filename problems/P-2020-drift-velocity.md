# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2020
หัวข้อ: ไฟฟ้ากระแส (วงจร)
หัวข้อย่อย: ความเร็วลอยเลื่อน
ระดับความยาก: 2
โจทย์: ลวดโลหะยาว $l$ ต่อกับความต่างศักย์ $V_0$ มีความเร็วลอยเลื่อน $u$ ถ้าเพิ่มความยาวลวดเป็นสองเท่าโดยความต่างศักย์เท่าเดิม ความเร็วลอยเลื่อนของอิเล็กตรอนจะเป็นเท่าใด
ตัวเลือก A: เท่าเดิม
ตัวเลือก B: $2u$
ตัวเลือก C: $\frac{u}{2}$
ตัวเลือก D: $4u$
ตัวเลือก E: $\frac{u}{4}$
คำตอบ: C
เฉลย: $v_d = \frac{I}{neA}$ และ $I = \frac{V}{R} = \frac{VA}{\rho l}$ → $v_d = \frac{V}{\rho l\,ne}$ แปรผกผันกับความยาว $l$. เพิ่ม l เป็น 2 เท่า → $v_d$ ลดครึ่ง = $\frac{u}{2}$
trap: ตอบ B — คิดว่าความต้านทานมากขึ้นความเร็วต้องมากขึ้น (แปรผันตรงผิด) #พลาด/นิยาม
