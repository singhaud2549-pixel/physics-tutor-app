# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้
id: O-1142
หัวข้อ: แรงและกฎนิวตัน
ระดับชั้น: ม.6
หัวข้อย่อย: หาสัมประสิทธิ์จากความเร่งที่วัดได้
ระดับความยาก: 4
โจทย์: มวล 4 kg วางบนพื้นราบ มีเชือกผูกพาดผ่านรอกไร้แรงเสียดทานไปแขวนมวล 3 kg ปล่อยระบบจากหยุดนิ่งแล้ววัดความเร่งของระบบได้ $2$ m/s$^2$ (กำหนด $g=10$ m/s$^2$) จงหาสัมประสิทธิ์แรงเสียดทานจลน์ระหว่างมวลบนพื้นกับพื้นราบ
หน่วย: - (ไม่มีหน่วย)
คำตอบ: 0.4
คลาดเคลื่อน:
เฉลย: ย้อนกลับจากผล: แรงลัพธ์ที่ทำให้มวลรวม $7$ kg เร่ง $2$ m/s$^2$ คือ $7(2)=14$ N แรงขับมีแค่น้ำหนักมวลแขวน $3(10)=30$ N ส่วนที่หายไปคือแรงเสียดทาน: $f_k=30-14=16$ N ได้ $\mu_k=f_k/N=16/(4(10))=0.4$ (ตรวจ: ถ้าไม่มีแรงเสียดทานเลยความเร่งจะเป็น $30/7=4.29$ มากกว่าที่วัดได้จริง สอดคล้องว่ามีแรงเสียดทาน)
trap: ตอบ 0.75 — เอา $30/40=0.75$ ลืมว่าไม่ใช่สมดุล มวลรวมมีความเร่งจึงต้องหักพจน์ $ma$ ออกก่อน #พลาด/สูตรผิด
trap: ตอบ 0.6 — เอาแรงตึงเชือก ($T=m(g-a)=3(8)=24$ N) มาตอบเป็นแรงเสียดทานเลย ($24/40=0.6$) ลืมว่าแรงตึงต้องหักพจน์เร่งของมวลบนพื้นอีกทอด #พลาด/แผนภาพแรง
