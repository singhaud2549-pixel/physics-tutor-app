# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1169
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: รางลูปผสมงาน-พลังงาน
ระดับความยาก: 3
โจทย์: ลูกบอลเล็กมวล $0.4$ kg ไถลลงมาจากรางโค้งลื่น (ไร้แรงเสียดทานตลอดเส้นทาง) โดยปล่อยจากหยุดนิ่งที่ความสูง $H = 2.0$ m เหนือจุดต่ำสุดของราง แล้ววิ่งเข้าสู่ห่วงวงกลมแนวดิ่งรัศมี $R = 0.5$ m ที่ต่อเชื่อมกับปลายราง (ดูรูปประกอบ) จงหาแรงปฏิกิริยาที่รางกระทำต่อลูกบอล ($N$) ขณะลูกบอลอยู่ที่จุดสูงสุดของห่วงวงกลม (หน่วยนิวตัน กำหนด $g=10$ m/s$^2$)

รูปจำเป็น: ใช่
หน่วย: นิวตัน (N)
คำตอบ: 12
คลาดเคลื่อน:
เฉลย: ขั้นที่ 1 หาอัตราเร็วที่จุดสูงสุดของห่วงด้วยงาน-พลังงาน รางลื่นจึงใช้การอนุรักษ์พลังงานกลได้ จากจุดปล่อย (สูง $H$ เหนือจุดต่ำสุด ความเร็วเป็นศูนย์) ไปยังจุดสูงสุดของห่วง (สูง $2R = 1.0$ m เหนือจุดต่ำสุด): $mgH = mg(2R) + \dfrac12mv_{top}^2$ ได้ $v_{top}^2 = 2g(H-2R) = 2(10)(2.0-1.0) = 20$ m$^2$/s$^2$. ขั้นที่ 2 วิเคราะห์แรงสู่ศูนย์กลางที่จุดสูงสุด: $N + mg = \dfrac{mv_{top}^2}{R}$ ดังนั้น $N = \dfrac{mv_{top}^2}{R} - mg = \dfrac{(0.4)(20)}{0.5} - (0.4)(10) = 16 - 4 = 12$ N (ตรวจอีกวิธีด้วยพลังงานตรงๆ: พลังงานรวม $mgH = 8$ J ศักย์ที่จุดสูงสุด $mg(2R) = 4$ J เหลือจลน์ $4$ J ได้ $v_{top}^2 = 2(4)/0.4 = 20$ เท่าเดิม แล้ว $N = 16-4 = 12$ N และ $N>0$ จึงวิ่งครบวงได้จริง)
trap: ตอบ 16 N — หา $v_{top}$ ด้วยพลังงานถูกต้องแล้ว แต่ลืมลบน้ำหนัก $mg$ ใช้ $N = mv^2/R$ อย่างเดียว โดยลืมว่าที่จุดสูงสุดน้ำหนักช่วยพุ่งเข้าศูนย์กลางอยู่แล้ว #พลาด/แผนภาพแรง
trap: ตอบ 28 N — ลืมลบความสูง $2R$ ของจุดสูงสุดของห่วง ใช้ $v^2 = 2gH = 40$ (เอาอัตราเร็วที่จุดต่ำสุดมาใช้ที่จุดสูงสุด) ได้ $N = (0.4)(40)/0.5 - 4 = 32-4 = 28$ N ทั้งที่ลูกบอลเสียพลังงานศักย์ไปแล้ว $mg(2R)$ #พลาด/พลังงาน
trap: ตอบ 20 N — เผลอใช้สูตรของจุดต่ำสุด $N = mg + mv^2/R = 4+16$ โดยลืมว่าที่จุดสูงสุดน้ำหนักพุ่งเข้าศูนย์กลาง (ช่วย) ไม่ใช่พุ่งออกจากศูนย์กลาง (ต้าน) #พลาด/แผนภาพแรง
trap: ตอบ 4 N — ตอบเพียงน้ำหนัก $mg = 4$ N โดยเข้าใจผิดว่าแรงที่รางกระทำเท่าน้ำหนักเสมอ ลืมว่าวัตถุเคลื่อนที่เป็นวงกลมอยู่ ต้องมีแรงสู่ศูนย์กลาง $mv^2/R$ #พลาด/แผนภาพแรง
