# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1017
หัวข้อ: สมดุลและโมเมนต์
หัวข้อย่อย: สมดุลโมเมนต์ของคานสม่ำเสมอที่ต้องรวมน้ำหนักคานเอง
ระดับความยาก: 3
โจทย์: คานสม่ำเสมอ (เนื้อคานสม่ำเสมอตลอดความยาว) ยาว $4$ m มวล $8$ kg วางพาดอยู่บนจุดหมุน (บานพับ) ที่ปลายด้านซ้าย (จุด A) โดยมีเชือกผูกดึงในแนวดิ่งขึ้นที่ปลายด้านขวา (จุด B) เพื่อรักษาให้คานอยู่ในแนวราบและสมดุล มีวัตถุมวล $12$ kg แขวนอยู่ที่ตำแหน่งห่างจากจุด A เป็นระยะ $1$ m (ดูรูปประกอบ) จงหาแรงตึงเชือกที่จุด B (หน่วยนิวตัน กำหนด $g=10$ m/s$^2$)
รูป: O-1017-beam.png
รูปจำเป็น: ไม่
ตัวเลือก A: 30 N
ตัวเลือก B: 70 N
ตัวเลือก C: 110 N
ตัวเลือก D: 7 N
ตัวเลือก E: 40 N
คำตอบ: B
เฉลย: ใช้เงื่อนไขสมดุลโมเมนต์ (ผลรวมโมเมนต์รอบจุดหมุน A เท่ากับศูนย์) เนื่องจากคานสม่ำเสมอ น้ำหนักของคานเองถือว่ากระทำที่จุดศูนย์กลางมวลของคาน คือตำแหน่งกึ่งกลางคาน ห่างจาก A เป็นระยะ $4/2=2$ m แรงที่ต้องนำมาคิดโมเมนต์รอบ A มีสามแรง: น้ำหนักวัตถุที่แขวน $W_{block}=12\times10=120$ N (แขนโมเมนต์ $1$ m) น้ำหนักคานเอง $W_{beam}=8\times10=80$ N (แขนโมเมนต์ $2$ m) และแรงตึงเชือก $T$ ที่จุด B (แขนโมเมนต์ $4$ m ดึงขึ้น ให้โมเมนต์ทวนเข็มหักล้างกับสองแรงแรกที่ทำให้คานหมุนตามเข็ม) สมการสมดุลโมเมนต์รอบ A: $T\times4 = W_{block}\times1 + W_{beam}\times2 = 120(1)+80(2)=120+160=280$ ดังนั้น $T = 280/4 = 70$ N
trap: ตอบ 30 N — ลืมรวมน้ำหนักของคานเองเข้าไปในสมการโมเมนต์ (คิดว่าคานเป็น "คานเบา" ไม่มีมวล) คำนวณจากวัตถุแขวนอย่างเดียว $T\times4=120(1) \Rightarrow T=30$ N ทั้งที่โจทย์ระบุมวลคานไว้ชัดเจนว่า 8 kg ไม่ใช่คานเบา จึงต้องนำน้ำหนักคานมาคิดโมเมนต์ด้วยเสมอ
trap: ตอบ 110 N — เข้าใจผิดว่าน้ำหนักของคานกระทำที่ปลาย B (ตำแหน่งเดียวกับจุดแขวนเชือก) แทนที่จะเป็นจุดกึ่งกลางคาน ใช้แขนโมเมนต์ผิดเป็น $4$ m แทน $2$ m ได้ $T\times4=120(1)+80(4)=440 \Rightarrow T=110$ N
trap: ตอบ 7 N — ลืมคูณด้วยค่า $g$ ในการหาน้ำหนัก ใช้ค่ามวล (kg) แทนน้ำหนัก (N) ตรงๆ ในสมการโมเมนต์ $T\times4=12(1)+8(2)=28 \Rightarrow T=7$ ทั้งที่โมเมนต์ต้องคำนวณจากแรง (น้ำหนัก) ไม่ใช่มวลเฉยๆ
trap: ตอบ 40 N — ลืมรวมโมเมนต์จากวัตถุที่แขวนไว้ (12 kg) คำนวณจากน้ำหนักคานเพียงอย่างเดียว $T\times4=80(2)=160 \Rightarrow T=40$ N
