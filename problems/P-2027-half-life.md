# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
# หมายเหตุ: ต้นฉบับมีตัวเลือกซ้ำ (A เท่ากับ C) — ปรับ C เป็นตัวลวงที่ต่างออกไปให้ใช้งานได้
id: P-2027
หัวข้อ: ฟิสิกส์นิวเคลียร์
หัวข้อย่อย: กัมมันตภาพและครึ่งชีวิต
ระดับความยาก: 2
โจทย์: ธาตุ X มีครึ่งชีวิต $T_X$ และจำนวนอะตอมแรกเริ่ม $N_0$ เมื่อเวลาผ่านไป $\tau$ ธาตุ X จะมีค่ากัมมันตภาพเท่าใด
ตัวเลือก A: $\frac{N_0 \ln 2}{T_X}\left(\frac{1}{2}\right)^{\tau/T_X}$
ตัวเลือก B: $\frac{N_0 \ln 2}{T_X}\,2^{\tau/T_X}$
ตัวเลือก C: $\frac{N_0 \ln 2}{\tau}\left(\frac{1}{2}\right)^{\tau/T_X}$
ตัวเลือก D: $\frac{N_0}{\tau}\,2^{\tau/T_X}$
ตัวเลือก E: $\frac{N_0}{T_X}\left(\frac{1}{2}\right)^{\tau/T_X}$
คำตอบ: A
เฉลย: จำนวนที่เหลือ $N = N_0\left(\frac{1}{2}\right)^{\tau/T_X}$. กัมมันตภาพ $A = \lambda N$, $\lambda = \frac{\ln 2}{T_X}$ → $A = \frac{N_0 \ln 2}{T_X}\left(\frac{1}{2}\right)^{\tau/T_X}$
trap: ตอบ E — ลืมคูณ $\ln 2$ ตอนแปลงครึ่งชีวิตเป็นค่าคงตัวการสลาย
trap: ตอบ B — ใช้ $2^{\tau/T_X}$ (เพิ่มขึ้น) แทน $(1/2)^{\tau/T_X}$ (สลายลดลง)
