# ที่มา: เทพฟิสิกส์ฯ (รัชพล/อมร) บทที่ 1 การเคลื่อนที่ในแนวเส้นตรง — external (รอตรวจคำตอบ)
id: P-1002
หัวข้อ: จลนศาสตร์
ระดับชั้น: ม.6
หัวข้อย่อย: เวกเตอร์-สเกลาร์
ระดับความยาก: 1
โจทย์: จากความสัมพันธ์ แรง = มวล × ความเร่ง, โมเมนตัม = มวล × ความเร็ว, อัตราเร็ว = ระยะทาง / เวลา, กำลัง = งาน / เวลา — สมการข้างต้นทั้งหมดมีปริมาณที่เป็นเวกเตอร์รวมทั้งหมดกี่ปริมาณ
ตัวเลือก A: 0 ปริมาณ
ตัวเลือก B: 1 ปริมาณ
ตัวเลือก C: 2 ปริมาณ
ตัวเลือก D: 3 ปริมาณ
ตัวเลือก E: 4 ปริมาณ
คำตอบ: C
เฉลย: ปริมาณที่เป็นผลลัพธ์ของสมการและเป็นเวกเตอร์คือ แรง และ โมเมนตัม (2 ปริมาณ) ส่วนอัตราเร็วและกำลังเป็นสเกลาร์
trap: ตอบ D — นับอัตราเร็วหรือกำลังเป็นเวกเตอร์ด้วย (จริง ๆ เป็นสเกลาร์)
trap: ตอบ B — นับได้แค่ตัวเดียว ลืมว่าโมเมนตัมก็เป็นเวกเตอร์
