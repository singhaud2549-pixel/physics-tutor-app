# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย

หัวข้อ: ความร้อนและแก๊ส
หัวข้อย่อย: กฎข้อที่หนึ่งของอุณหพลศาสตร์
ระดับความยาก: 4
โจทย์: แก๊สอุดมคติอะตอมเดี่ยวขยายตัวแบบความดันคงที่ 2.0×10⁵ ปาสคาล ปริมาตรเปลี่ยนจาก 2.0 เป็น 2.4 ลิตร อุณหภูมิเปลี่ยนจาก 25 เป็น 85 องศาเซลเซียส หากนำแก๊สนี้ที่ 25 องศาเซลเซียส ไปให้ความร้อน 1,800 จูล จนอุณหภูมิเป็น 80 องศาเซลเซียส แก๊สจะทำงานกี่จูล (ตอบเป็นจำนวนเต็ม)
หน่วย: จูล (J)
คำตอบ: 1690
เฉลย: ครั้งแรก (ความดันคงที่): W1 = PΔV = 2.0×10⁵ × 0.4×10⁻³ = 80 J, ΔT = 60 K → nR = 80/60 = 4/3 J/K. ครั้งที่สอง ΔT = 55 K → ΔU = (3/2)nRΔT = (3/2)(4/3)(55) = 110 J. กฎข้อ 1: Q = ΔU + W → 1800 = 110 + W → W = 1690 J
