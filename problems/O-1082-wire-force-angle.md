# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1082
หัวข้อ: แม่เหล็กไฟฟ้า
หัวข้อย่อย: แรงแม่เหล็กบนลวดตัวนำกระแสไฟฟ้าที่วางทำมุมกับสนามแม่เหล็ก (ไม่ตั้งฉาก)
ระดับความยาก: 2
โจทย์: ลวดตัวนำตรงยาว 0.8 m มีกระแสไฟฟ้า 4 A ไหลผ่าน วางอยู่ในสนามแม่เหล็กสม่ำเสมอขนาด 0.5 T โดยตัวลวดทำมุม 30° กับแนวสนามแม่เหล็ก (ไม่ตั้งฉากกัน) จงหาขนาดของแรงแม่เหล็กที่กระทำต่อลวดเส้นนี้ (นิวตัน)
หน่วย: N
คำตอบ: 0.8
คลาดเคลื่อน: 0.02
เฉลย: สูตรแรงแม่เหล็กบนลวดตัวนำกระแสไฟฟ้าในสนามแม่เหล็กคือ $F = BIL\sin\theta$ โดย $\theta$ คือมุมระหว่างทิศของกระแส (แนวลวด) กับทิศของสนามแม่เหล็ก — โจทย์นี้ให้มุมนี้มาตรงๆ แล้วคือ 30° จึงไม่ต้องแปลงมุม แทนค่าได้เลย: $F = (0.5)(4)(0.8)\sin30° = 1.6\times0.5 = 0.8$ N
trap: ตอบ 1.39 — ใช้ $\cos30°$ แทน $\sin30°$ สับสนว่ามุมที่ให้มาต้องใช้กับโคไซน์ (สลับฟังก์ชันตรีโกณมิติผิด) ได้ $F=1.6\times\cos30°=1.6\times0.866\approx1.39$ N
trap: ตอบ 1.6 — ลืมพิจารณามุมที่ลวดทำกับสนามแม่เหล็กไปเลย คิดว่าลวดตั้งฉากกับสนามพอดี (ใช้ $\sin\theta=1$) ได้ $F=BIL=1.6$ N
trap: ตอบ 3.2 — หารด้วย $\sin30°$ แทนที่จะคูณ (สลับทิศทางของสูตร) ได้ $F=1.6/0.5=3.2$ N
