# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1039
หัวข้อ: ไฟฟ้าสถิต
หัวข้อย่อย: แรงคูลอมบ์ — ผลรวมเวกเตอร์จากประจุหลายจุดบนสามเหลี่ยมมุมฉาก
ระดับความยาก: 3
โจทย์: จากรูป มีประจุ $+q$ วางอยู่ที่จุด A (จุดกำเนิด) มีประจุ $-2q$ วางอยู่ที่จุด B ห่างจาก A เป็นระยะ $a$ ตามแนวแกน x และมีประจุ $+q$ อีกตัวหนึ่งวางอยู่ที่จุด C ห่างจาก A เป็นระยะ $a$ ตามแนวแกน y (มุมที่จุด A เป็นมุมฉากพอดี) กำหนด $q = 2$ μC, $a = 0.30$ m, $k = 9\times10^9$ N·m²/C² จงหาขนาดของแรงลัพธ์ทางไฟฟ้าที่กระทำต่อประจุที่จุด A
รูป: O-1039-coulomb-triangle.png
รูปจำเป็น: ใช่
ตัวเลือก A: 0.400 N
ตัวเลือก B: 0.566 N
ตัวเลือก C: 0.825 N
ตัวเลือก D: 0.894 N
ตัวเลือก E: 1.200 N
คำตอบ: D
เฉลย: แรงจาก B กระทำต่อ A: ประจุตรงข้ามเครื่องหมาย ($+q$ กับ $-2q$) จึงดึงดูดกัน ทิศพุ่งจาก A ไปทาง B (แนวแกน +x) ขนาด $F_{AB}=\dfrac{k(q)(2q)}{a^2}=\dfrac{9\times10^9\times(2\times10^{-6})(4\times10^{-6})}{(0.3)^2}=\dfrac{9\times10^9\times8\times10^{-12}}{0.09}=0.8$ N. แรงจาก C กระทำต่อ A: ประจุเครื่องหมายเดียวกัน ($+q$ กับ $+q$) จึงผลักกัน ทิศพุ่งออกจาก C ผ่าน A ต่อไป (แนวแกน −y) ขนาด $F_{AC}=\dfrac{k q^2}{a^2}=\dfrac{9\times10^9\times(2\times10^{-6})^2}{0.09}=\dfrac{9\times10^9\times4\times10^{-12}}{0.09}=0.4$ N. เนื่องจากแรงทั้งสองตั้งฉากกันพอดี (แนวแกน x กับ y) จึงรวมแบบเวกเตอร์ด้วยพีทาโกรัส: $F=\sqrt{F_{AB}^2+F_{AC}^2}=\sqrt{0.8^2+0.4^2}=\sqrt{0.64+0.16}=\sqrt{0.80}\approx0.894$ N (ตรวจสอบอีกวิธี: $\sqrt{0.80}=\sqrt{4/5}=2/\sqrt5\approx0.8944$ ตรงกัน)
trap: ตอบ A (0.400) — ลืมรวมแรงจาก B เข้าไปด้วย คำนวณแค่แรงจาก C เพียงอย่างเดียวแล้วตอบเลย #พลาด/ข้ามขั้น
trap: ตอบ B (0.566) — อ่านประจุที่ B ผิด คิดว่า "$-2q$" หมายถึงประจุ $-2$ μC ตรง ๆ (ไม่ใช่ $-2$ เท่าของ $q=2$ μC ซึ่งจริง ๆ คือ $-4$ μC) ทำให้ได้ $F_{AB}'=\dfrac{k(2\times10^{-6})(2\times10^{-6})}{0.09}=0.4$ N เท่ากับ $F_{AC}$ พอดี รวมเวกเตอร์ได้ $\sqrt{0.4^2+0.4^2}\approx0.566$ N #พลาด/อ่านโจทย์
trap: ตอบ C (0.825) — ใช้ระยะทางผิดสำหรับแรงจาก C โดยเผลอใช้ระยะทแยงมุม (เส้น BC) แทนระยะ $a$ จริงตามโจทย์ (สับสนว่าระยะจาก A ถึง C ควรเป็นด้านตรงข้ามมุมฉาก) ทำให้ระยะเพิ่มเป็น $a\sqrt2$ แรงจึงลดลงครึ่งหนึ่ง $F_{AC}'=0.4/2=0.2$ N รวมกับ $F_{AB}=0.8$ N ได้ $\sqrt{0.8^2+0.2^2}=\sqrt{0.68}\approx0.825$ N #พลาด/แทนค่า
trap: ตอบ E (1.200) — รวมแรงแบบสเกลาร์ตรง ๆ (บวกขนาดสองแรงเข้าด้วยกัน) แทนที่จะรวมแบบเวกเตอร์ตั้งฉากด้วยพีทาโกรัส ได้ $0.8+0.4=1.2$ N #พลาด/แผนภาพแรง
