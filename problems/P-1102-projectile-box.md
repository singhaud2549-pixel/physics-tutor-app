# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-1102
หัวข้อ: โพรเจกไทล์
หัวข้อย่อย: ความเร็วและเวลาในการเคลื่อนที่
ระดับความยาก: 3
โจทย์: ยิงวัตถุด้วยความเร็วต้น 12.0 m/s ทำมุม 53° กับพื้น พบว่าเคลื่อนที่พ้นกล่องพอดี โดยความเร็วขณะเฉียดขอบบนของกล่องทั้งสองครั้งทำมุม 37° กับแนวระดับ ดังรูป จงหาเวลาที่วัตถุอยู่เหนือกล่องกี่วินาที (คำตอบติดตัวแปร $g$)
รูป: P-1102-projectile.png
รูปจำเป็น: ใช่
ตัวเลือก A: $\frac{10.8}{g}$
ตัวเลือก B: $\frac{4.2}{g}$
ตัวเลือก C: $\frac{1}{g}$
ตัวเลือก D: $\frac{15}{g}$
ตัวเลือก E: $2g$
คำตอบ: A
เฉลย: $v_x = 12\cos53° = 7.2$ m/s (คงที่). ที่ขอบกล่องมุม 37° → $v_y = v_x\tan37° = 7.2(0.75) = 5.4$ m/s (ขาขึ้น) และ $-5.4$ (ขาลง). เวลาเหนือกล่อง: $-5.4 = 5.4 - gt$ → $t = \frac{10.8}{g}$
trap: ตอบ B — คำนวณ $v_y$ ตอนเฉียดกล่องผิด
