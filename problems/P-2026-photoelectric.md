# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2026
หัวข้อ: ฟิสิกส์อะตอม/ควอนตัม
หัวข้อย่อย: โฟโตอิเล็กทริกและเดอบรอยล์
ระดับความยาก: 3
โจทย์: ฉายแสงความยาวคลื่น $\lambda_0$ บนโลหะที่มีฟังก์ชันงาน $W$ เกิดโฟโตอิเล็กตรอนหลุดออกมา จงหาความยาวคลื่นเดอบรอยล์ของโฟโตอิเล็กตรอนที่มีพลังงานจลน์สูงสุด (อิเล็กตรอนมวล $m$ ไม่สัมพัทธภาพ)
ตัวเลือก A: $h\sqrt{\frac{\lambda_0}{2mhc}}$
ตัวเลือก B: $h\sqrt{\frac{1}{2mW}}$
ตัวเลือก C: $h\sqrt{\frac{\lambda_0}{2m(hc - \lambda_0 W)}}$
ตัวเลือก D: $h\sqrt{\frac{\lambda_0}{2m(hc + \lambda_0 W)}}$
ตัวเลือก E: $\lambda_0$
คำตอบ: C
เฉลย: $K_{max} = \frac{hc}{\lambda_0} - W = \frac{hc - \lambda_0 W}{\lambda_0}$. เดอบรอยล์ $\lambda = \frac{h}{\sqrt{2mK_{max}}} = h\sqrt{\frac{\lambda_0}{2m(hc - \lambda_0 W)}}$
trap: ตอบ D — สลับเครื่องหมายฟังก์ชันงานเป็นบวกในสมการโฟโตอิเล็กทริก
