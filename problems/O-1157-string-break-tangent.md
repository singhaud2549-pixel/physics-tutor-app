# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1157
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: เชือกขาดแนวเส้นสัมผัส
ระดับความยาก: 3
โจทย์: จุกยางผูกเชือกแกว่งเป็นวงกลมสม่ำเสมอในระนาบระดับ มองจากด้านบนเห็นจุกยางเคลื่อนที่ทวนเข็มนาฬิกา ทันทีที่จุกยางผ่านจุด X (จุดขวาสุดของวงกลม) เชือกก็ขาดออกจากกันพอดี (ดูรูปประกอบ) หลังจากนั้นจุกยางจะเคลื่อนที่อย่างไร (ไม่คิดแรงต้านอากาศ)
ตัวเลือก A: วิ่งเป็นเส้นตรงต่อไปในทิศที่กำลังเคลื่อนที่ขณะเชือกขาด (แนวเส้นสัมผัสวงกลมที่จุด X)
ตัวเลือก B: พุ่งออกไปเป็นเส้นตรงตามแนวรัศมี ผ่านจุด X ออกจากศูนย์กลางวงกลม
ตัวเลือก C: เคลื่อนที่เป็นเส้นโค้งวนออกห่างจากวงกลมเดิมแบบก้นหอย
ตัวเลือก D: หยุดนิ่งที่จุด X ทันที แล้วร่วงลงตรงๆ
ตัวเลือก E: ยังคงวิ่งโค้งตามแนววงกลมเดิมต่อไปอีกสักพัก แล้วค่อยหลุดออกไป
คำตอบ: A
เฉลย: ขณะเชือกขาด จุกยางมีความเร็วทิศตามแนวเส้นสัมผัสวงกลมที่จุด X (ชี้ขึ้นตามรูป) แรงสู่ศูนย์กลางจากเชือกหายไปทันทีที่เชือกขาด จึงไม่มีแรงในแนวระดับมาเปลี่ยนทิศความเร็วอีก ตามกฎการเคลื่อนที่ข้อที่ 1 ของนิวตัน (ความเฉื่อย) วัตถุต้องรักษาสภาพการเคลื่อนที่เดิมไว้ คือวิ่งเป็นเส้นตรงด้วยความเร็วเดิมต่อไปตามแนวเส้นสัมผัส ไม่มีการพุ่งออกตามแนวรัศมีเพราะไม่เคยมีแรงผลักออกตั้งแต่แรก

trap: ตอบ B — เชื่อว่ามี "แรงเหวี่ยง" ผลักวัตถุออกจากศูนย์กลางมาตลอด พอเชือกขาดแรงนี้เลยดันวัตถุพุ่งออกตามแนวรัศมี ทั้งที่แรงเหวี่ยงไม่มีอยู่จริงในกรอบเฉื่อย แรงจริงมีเพียงแรงตึงเชือกที่ดึงเข้าศูนย์กลางเท่านั้น พอแรงนี้หายไปก็ไม่มีอะไรผลักออก #พลาด/แรงเหวี่ยง #trap/178
trap: ตอบ C — คิดว่าวัตถุยังมี "ความโค้งติดค้าง" ทำให้วิ่งโค้งต่อไปได้เอง ทั้งที่การเปลี่ยนทิศต้องมีแรงสุทธิมากระทำเสมอ เมื่อไม่มีแรงในแนวระดับแล้ว เส้นทางต้องเป็นเส้นตรงเท่านั้น ไม่ใช่เส้นโค้ง #พลาด/กฎนิวตันข้อ1
trap: ตอบ D — เข้าใจผิดว่าแรงตึงเชือกเป็นสิ่งที่ "พาวัตถุเคลื่อนที่" พอเชือกขาดเลยหยุด ทั้งที่แรงตึงเชือกทำหน้าที่แค่เปลี่ยนทิศความเร็ว ไม่ได้เป็นตัวรักษาอัตราเร็ว ความเฉื่อยต่างหากที่ทำให้วัตถุวิ่งต่อไป #พลาด/ความเฉื่อย
trap: ตอบ E — คิดว่าวัตถุมี "ความจำเส้นทาง" วิ่งตามวงกลมต่อได้เองสักพัก ทั้งที่วงกลมเดิมเกิดจากแรงตึงเชือกดึงเข้าศูนย์กลางตลอดเวลา เมื่อแรงนี้หายไปเงื่อนไขการเป็นวงกลมก็หายไปทันที ไม่มีช่วงเปลี่ยนผ่าน #พลาด/กฎนิวตันข้อ1
