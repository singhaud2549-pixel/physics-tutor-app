# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2015
หัวข้อ: เสียง
หัวข้อย่อย: ปรากฏการณ์ดอปเพลอร์
ระดับความยาก: 3
โจทย์: ผู้สังเกตอยู่นิ่ง วัดความถี่ไซเรนจากรถพยาบาลที่วิ่งตรงเข้าหาได้ 700 เฮิรตซ์ ต่อมาขณะรถวิ่งห่างออกไป วัดได้ 580 เฮิรตซ์ อัตราส่วนของอัตราเร็วรถพยาบาลต่ออัตราเร็วเสียงในอากาศเท่ากับข้อใด

ตัวเลือก C: 3/32
ตัวเลือก D: 4/29
ตัวเลือก E: 5/12
คำตอบ: C
