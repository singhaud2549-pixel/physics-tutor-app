# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1030
หัวข้อ: ของไหล
หัวข้อย่อย: หลักพาสคาลในระบบไฮดรอลิกที่ลูกสูบอยู่คนละระดับความสูง
ระดับความยาก: 4
โจทย์: เครื่องอัดไฮดรอลิกเครื่องหนึ่งใช้น้ำมัน (ความหนาแน่น 800 kg/m$^3$) เป็นของไหลส่งผ่านแรง ลูกสูบเล็กมีพื้นที่หน้าตัด 5 cm$^2$ อยู่สูงกว่าลูกสูบใหญ่ซึ่งมีพื้นที่หน้าตัด 250 cm$^2$ เป็นระยะ 2 m (วัดตามแนวดิ่ง) ถ้าออกแรงกด 100 N ลงบนลูกสูบเล็ก (ในแนวดิ่ง) จงหาแรงที่ลูกสูบใหญ่สามารถดันรับน้ำหนักได้ (กำหนด $g=10$ m/s$^2$)
ตัวเลือก A: 4,600 N
ตัวเลือก B: 5,000 N
ตัวเลือก C: 5,400 N
ตัวเลือก D: 5,200 N
ตัวเลือก E: 21,000 N
คำตอบ: C
เฉลย: เนื่องจากลูกสูบทั้งสองอยู่คนละระดับความสูง ต้องคิดความดันจากน้ำหนักของน้ำมันในช่วงที่สูงต่างกันเพิ่มเข้าไปกับหลักพาสคาลด้วย ไม่ใช่ใช้อัตราส่วนพื้นที่ตรงๆ ก่อนอื่นแปลงหน่วยพื้นที่: $A_2=5\text{ cm}^2=5\times10^{-4}$ m$^2$ (ลูกสูบเล็ก), $A_1=250\text{ cm}^2=0.025$ m$^2$ (ลูกสูบใหญ่) ความดันที่ลูกสูบเล็ก $P_2=\frac{F_2}{A_2}=\frac{100}{5\times10^{-4}}=2\times10^5$ Pa เนื่องจากลูกสูบเล็กอยู่สูงกว่า ความดันที่ระดับลูกสูบใหญ่ (ระดับต่ำกว่า) จะมากกว่าความดัน $P_2$ อยู่เท่ากับน้ำหนักของน้ำมันในช่วงสูงต่างกัน: $P_1=P_2+\rho gh=2\times10^5+(800)(10)(2)=2\times10^5+1.6\times10^4=2.16\times10^5$ Pa แรงที่ลูกสูบใหญ่รับได้ $F_1=P_1A_1=(2.16\times10^5)(0.025)=5{,}400$ N (ตรวจสอบอีกวิธี: $F_1=F_2\times\frac{A_1}{A_2}+\rho gh\times A_1=100\times50+16{,}000\times0.025=5{,}000+400=5{,}400$ N ตรงกัน)
trap: ตอบ 5,000 N — ใช้หลักพาสคาลแบบพื้นฐาน $F_1=F_2\times(A_1/A_2)=100\times50=5{,}000$ N โดยไม่คิดผลต่างความสูงของน้ำมันในท่อเลย (ลืมพจน์ $\rho gh$ ทั้งหมด)
trap: ตอบ 4,600 N — คิดพจน์ผลต่างความสูงกลับทิศ (ลบแทนที่จะบวก) โดยเข้าใจผิดว่าลูกสูบเล็กอยู่สูงกว่าทำให้ความดันที่ลูกสูบใหญ่ลดลง แทนที่จะเพิ่มขึ้น ได้ $F_1=5{,}000-400=4{,}600$ N
trap: ตอบ 5,200 N — คิดพจน์ผลต่างความสูงถูกทิศทาง (บวก) แต่หารสองส่วนแก้ไขระยะสูงเป็นครึ่งหนึ่งโดยไม่มีเหตุผลรองรับ (ใช้ $h/2=1$ m แทน $h=2$ m เต็ม) ได้ผลบวกเพิ่มแค่ 200 N แทนที่จะเป็น 400 N
trap: ตอบ 21,000 N — สับสนระหว่างพจน์ความดัน ($\rho gh$) กับแรง โดยนำ $\rho gh=16{,}000$ Pa ไปบวกกับแรง $F_2/A_2\times A_1$ ตรงๆ โดยไม่คูณ $\rho gh$ ด้วยพื้นที่ $A_1$ ก่อน (สับสนมิติ Pa กับ N) ได้ $F_1=5{,}000+16{,}000=21{,}000$ N
