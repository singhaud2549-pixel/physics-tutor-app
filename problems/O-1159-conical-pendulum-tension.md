# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1159
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: ลูกตุ้มกรวยคาบการแกว่ง
ระดับความยาก: 1
โจทย์: ลูกตุ้มมวล $0.25$ kg ผูกติดกับเชือกเบายาว $0.26$ m แล้วแกว่งเป็นวงกลมสม่ำเสมอในระนาบระดับ (ลูกตุ้มกรวย) ด้วยความถี่ $1$ Hz โดยมุมที่เชือกทำกับแนวดิ่งมีค่าเล็กมาก จงหาแรงตึงในเส้นเชือก (กำหนดให้ $\pi^2 \approx 10$ และ $g=10$ m/s$^2$)
หน่วย: นิวตัน (N)
คำตอบ: 2.6
คลาดเคลื่อน: 2
เฉลย: แตกแรงตึงเชือก $T$ เป็นสองแกน แกนดิ่งสมดุล $T\cos\theta = mg$ ส่วนแนวระดับให้แรงสู่ศูนย์กลาง $T\sin\theta = m\omega^2 r$ โดย $r = L\sin\theta$ และ $\omega = 2\pi f$ แทน $r$ ลงไป $\sin\theta$ ตัดกันทั้งสองข้าง ได้ $T = m\omega^2 L = m(2\pi f)^2 L = 4\pi^2 m f^2 L = (40)(0.25)(1)^2(0.26) = 2.6$ N (ตรวจอีกวิธี: จากแกนดิ่ง $\cos\theta = mg/T = 2.5/2.6 \approx 0.96$ ได้ $\theta \approx 16^\circ$ ซึ่งเล็กจริง สอดคล้องกับเงื่อนไขโจทย์ และ $r = L\sin\theta \approx 0.072$ m ให้ $T\sin\theta \approx 0.72$ N เท่ากับ $m\omega^2 r = (0.25)(40)(0.072) \approx 0.72$ N ตรงกัน)
trap: ตอบ 2.5 — เข้าใจผิดว่าเชือกห้อยนิ่งอยู่ในสมดุล จึงตอบแค่ $T = mg = 2.5$ N โดยลืมว่าลูกตุ้มกำลังเคลื่อนที่เป็นวงกลม ต้องมีองค์ประกอบแรงแนวระดับมาทำหน้าที่เป็นแรงสู่ศูนย์กลาง ทำให้ $T$ ต้องมากกว่า $mg$ เสมอ ($T\cos\theta = mg$ จึง $T = mg/\cos\theta > mg$) #พลาด/แผนภาพแรง
trap: ตอบ 0.065 — ใช้ $\omega = f$ ตรงๆ ลืมคูณ $2\pi$ ได้ $T = mf^2L = (0.25)(1)(0.26) = 0.065$ N (ลืมว่าความถี่ $f$ หน่วยรอบต่อวินาที ต้องแปลงเป็นอัตราเร็วเชิงมุม $\omega = 2\pi f$ ก่อน) #พลาด/สูตรผิด
trap: ตอบ 10.4 — ลืมคูณมวล $m$ ใช้ $T = (2\pi f)^2 L = (40)(0.26) = 10.4$ N (ตั้งสมการแรงสู่ศูนย์กลางแต่ลืมว่ามวลต้องคูณอยู่ด้วย $F_c = m\omega^2 r$) #พลาด/ตัวแปรไม่ครบ
trap: ตอบ 0.65 — ใช้ $\omega = \pi f$ (หารสองเกินจาก $2\pi f$) ได้ $T = m(\pi f)^2 L = (10)(0.25)(0.26) = 0.65$ N (จำตัวประกอบ $2\pi$ ผิด มักมาจากจำสลับกับสูตรคาบ $T = 2\pi/\omega$) #พลาด/สูตรผิด
