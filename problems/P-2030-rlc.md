# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2030
หัวข้อ: ไฟฟ้ากระแสสลับ
หัวข้อย่อย: ความต่างศักย์สูงสุดในวงจร RLC
ระดับความยาก: 3
โจทย์: นำตัวต้านทาน 60 โอห์ม ต่ออนุกรมกับตัวเหนี่ยวนำ $\frac{0.8}{\pi}$ เฮนรี แล้วนำสายนี้ไปต่อขนานกับแหล่งกำเนิดไฟฟ้ากระแสสลับ $V = 300\sin(100\pi t + \frac{5\pi}{3})$ โวลต์ จงหาความต่างศักย์สูงสุดคร่อมตัวต้านทาน
หน่วย: โวลต์ (V)
คำตอบ: 180
เฉลย: สาย R–L คร่อมแหล่งกำเนิด → แรงดันสูงสุด 300 V. $X_L = \omega L = 100\pi \cdot \frac{0.8}{\pi} = 80\ \Omega$. $Z = \sqrt{60^2+80^2} = 100\ \Omega$. กระแสสูงสุด I = 300/100 = 3 A. แรงดันคร่อม R: $V_R = IR = 3 \times 60 = 180$ V
trap: ตอบ 300 — เอาแรงดันสูงสุดของแหล่งกำเนิดมาตอบ ลืมว่าแบ่งไปตกคร่อมตัวเหนี่ยวนำด้วย #พลาด/ข้ามขั้น
