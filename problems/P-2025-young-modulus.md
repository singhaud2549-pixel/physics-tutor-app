# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2025
หัวข้อ: ของแข็ง
หัวข้อย่อย: มอดูลัสของยัง
ระดับความยาก: 3
โจทย์: ลวดโลหะมีมอดูลัสของยัง $Y$ พื้นที่หน้าตัด $A$ เมื่อแขวนมวล $M$ ที่ปลายลวด พบว่าลวดยาว $L$ หากแขวนมวล $m$ เพิ่ม ลวดจะยืดเพิ่มขึ้นเท่าใด
ตัวเลือก A: $\frac{mgL}{Mg+YA}$
ตัวเลือก B: $\frac{MgL}{Mg+YA}$
ตัวเลือก C: $\frac{mgL}{YA}$
ตัวเลือก D: $\frac{mgL}{mg+YA}$
ตัวเลือก E: $\frac{MgL}{mg+YA}$
คำตอบ: A
เฉลย: ความยาว L เป็นความยาว "หลังยืด" ไม่ใช่ตั้งต้น. ให้ตั้งต้น L₀: จาก Y = (Mg/A)/((L−L₀)/L₀) → L₀ = L·YA/(YA+Mg). ยืดเพิ่มเมื่อโหลด m: Δx = mg·L₀/YA = mgL/(Mg+YA)
trap: ตอบ C — ลืมว่า L เป็นความยาวหลังยืดแล้วรอบแรก ไม่ใช่ความยาวตั้งต้น L₀ #พลาด/แทนค่า
