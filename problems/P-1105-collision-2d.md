# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-1105
หัวข้อ: โมเมนตัมและการชน
หัวข้อย่อย: การชนใน 2 มิติ
ระดับความยาก: 3
โจทย์: ยิงลูกบอล A ความเร็ว 5.0 m/s ตามแกน x เข้าชนลูกบอล B ที่อยู่นิ่ง มวลลูกละ 1.0 kg หลังชน A ทำมุม 37° กับแกน x และ B ทำมุม 53° กับแกน x ดังรูป จงหาอัตราเร็ว $v_A$ (เมตรต่อวินาที)
รูป: P-1105-collision.png
รูปจำเป็น: ใช่
ตัวเลือก A: 1.5
ตัวเลือก B: 3.0
ตัวเลือก C: 4.0
ตัวเลือก D: 4.5
ตัวเลือก E: 6.0
คำตอบ: C
เฉลย: อนุรักษ์โมเมนตัมแกน y: $v_A\sin37° = v_B\sin53°$ → $v_B = 0.75\,v_A$. แกน x: $5.0 = v_A\cos37° + v_B\cos53° = 0.8v_A + 0.6(0.75v_A) = 1.25v_A$ → $v_A = 4.0$ m/s
trap: ตอบ B — สลับ $v_A$ กับ $v_B$ หรือใช้ตรีโกณผิดมุม #พลาด/แทนค่า
