# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1114
หัวข้อ: ของไหล
หัวข้อย่อย: แรงลัพธ์จากความดันของเหลวบนประตูระบายน้ำที่ความกว้างแปรผันตามความลึก (อินทิเกรต $\int \rho g y\, b(y)\, dy$)
ระดับความยาก: 5
โจทย์: ผนังเขื่อนแนวดิ่งบานหนึ่งมีประตูระบายน้ำรูปสามเหลี่ยม ติดตั้งอยู่ในระนาบดิ่ง โดยขอบบนของประตูเป็นด้านตรงยาว $w = 3.0$ m วางอยู่ที่ระดับผิวน้ำพอดี และยอดแหลม (จุดยอดล่าง) อยู่ลึกลงไป $H = 2.0$ m ใต้ผิวน้ำ ดังรูป ด้านหน้าประตูมีน้ำเต็ม ส่วนด้านหลังประตูเป็นอากาศที่ความดันบรรยากาศ กำหนดความหนาแน่นของน้ำ $\rho = 1000$ kg/m$^{3}$ และ $g = 10$ m/s$^{2}$ จงหาขนาดของแรงลัพธ์ที่น้ำกระทำต่อประตูบานนี้ (คิดเฉพาะความดันเกจ เพราะความดันบรรยากาศดันอยู่ทั้งสองด้านของประตูจึงหักล้างกันหมด)
รูป: O-1114-triangular-gate.png
รูปจำเป็น: ใช่
ตัวเลือก A: $2.0\times10^{4}$ N
ตัวเลือก B: $3.0\times10^{4}$ N
ตัวเลือก C: $4.0\times10^{4}$ N
ตัวเลือก D: $6.0\times10^{4}$ N
ตัวเลือก E: $1.2\times10^{5}$ N
คำตอบ: A
เฉลย: ความดันเกจของน้ำเพิ่มขึ้นตามความลึก $p(y)=\rho g y$ (ไม่คงที่ทั้งบาน) และประตูนี้ความกว้างก็ไม่คงที่ด้วย จึงใช้ $F=pA$ ตรงๆ ไม่ได้เลย ต้องอินทิเกรตแถบแนวนอนบางๆ  ขั้นที่ 1 — หาความกว้างเป็นฟังก์ชันของความลึก: ที่ผิวน้ำ ($y=0$) กว้าง $w=3.0$ m ที่ยอดแหลม ($y=H=2.0$ m) กว้าง 0 และขอบทั้งสองเป็นเส้นตรง ดังนั้นความกว้างลดลงเชิงเส้น: $b(y)=w\left(1-\dfrac{y}{H}\right)=3.0\left(1-\dfrac{y}{2.0}\right)$  ขั้นที่ 2 — ตั้งปริพันธ์ แถบที่ความลึก $y$ หนา $dy$ มีพื้นที่ $dA=b(y)\,dy$ และรับแรง $dF=p(y)\,dA=\rho g y\, b(y)\,dy$  $\displaystyle F=\int_0^{H}\rho g y\, w\left(1-\frac{y}{H}\right)dy = \rho g w\int_0^{H}\left(y-\frac{y^{2}}{H}\right)dy = \rho g w\left[\frac{y^{2}}{2}-\frac{y^{3}}{3H}\right]_0^{H} = \rho g w\left(\frac{H^{2}}{2}-\frac{H^{2}}{3}\right)=\frac{\rho g w H^{2}}{6}$  ขั้นที่ 3 — แทนค่า: $F=\dfrac{(1000)(10)(3.0)(2.0)^{2}}{6}=\dfrac{120000}{6}=20000$ N $=2.0\times10^{4}$ N  (ตรวจสอบซ้ำอีกวิธี — ใช้ทฤษฎีบท "แรงลัพธ์ = ความดันที่จุดเซนทรอยด์ของพื้นที่ คูณพื้นที่ทั้งหมด" ($F=\rho g\bar{y}A$) ซึ่งเป็นสูตรทั่วไปที่ได้จากนิยามของเซนทรอยด์ $\bar y = \frac{1}{A}\int y\,dA$ พอดี: เซนทรอยด์ของสามเหลี่ยมที่มีฐานอยู่ที่ผิวน้ำและยอดชี้ลง อยู่ลึก $\bar{y}=\dfrac{H}{3}=\dfrac{2.0}{3}$ m พื้นที่ประตู $A=\dfrac{1}{2}wH=\dfrac{1}{2}(3.0)(2.0)=3.0$ m$^{2}$ ได้ $F=(1000)(10)\left(\dfrac{2}{3}\right)(3.0)=20000$ N ตรงกับการอินทิเกรตพอดี และตรวจด้วยการอินทิเกรตเชิงตัวเลข (numerical quadrature) ก็ได้ $20000.0$ N เท่ากันทุกหลัก  หมายเหตุเสริม — ตำแหน่งแนวแรง (center of pressure) หาได้จาก $y_{cp}=\dfrac{\int y\,dF}{\int dF}=\dfrac{\rho g w\left(\frac{H^{3}}{3}-\frac{H^{3}}{4}\right)}{\rho g w H^{2}/6}=\dfrac{H}{2}=1.0$ m ซึ่งลึกกว่าเซนทรอยด์ของพื้นที่ ($H/3\approx0.67$ m) เสมอ เพราะความดันด้านล่างมากกว่า)
trap: ตอบ $6.0\times10^{4}$ N — ใช้ความดันที่จุดลึกสุด (ก้นประตู) $\rho gH=20000$ Pa คูณพื้นที่ประตูจริง $3.0$ m$^{2}$ ได้ $60000$ N เป็นตัวลวงคลาสสิกของบทของไหล: ความดันของเหลวที่กระทำต่อผนังตั้งฉากมีการกระจายแบบสามเหลี่ยม (เพิ่มตามความลึก) ต้องใช้ค่าเฉลี่ยแบบถ่วงน้ำหนักตามพื้นที่ ไม่ใช่ค่าความดันสูงสุดที่ก้น ซึ่งจะให้แรงเกินจริงถึง 3 เท่าในกรณีนี้ #พลาด/เงื่อนไข
trap: ตอบ $3.0\times10^{4}$ N — รู้ว่าต้องใช้ความดันเฉลี่ย แต่ใช้ความดันที่ "กึ่งกลางความลึก" $\rho g\dfrac{H}{2}=10000$ Pa คูณพื้นที่ $3.0$ m$^{2}$ ได้ $30000$ N — สูตร $\rho g\dfrac{H}{2}A$ ใช้ได้เฉพาะประตูรูป**สี่เหลี่ยมผืนผ้า**ที่ความกว้างคงที่เท่านั้น (เพราะเซนทรอยด์อยู่กึ่งกลางพอดี) ประตูสามเหลี่ยมยอดชี้ลงมีเนื้อที่ส่วนใหญ่อยู่ใกล้ผิวน้ำ เซนทรอยด์จึงอยู่ที่ $H/3$ ไม่ใช่ $H/2$ #พลาด/เงื่อนไข
trap: ตอบ $4.0\times10^{4}$ N — ใช้สูตร $F=\rho g\bar{y}A$ โดยรู้ว่าเซนทรอยด์อยู่ที่ $\bar y=H/3$ ถูกต้อง แต่ใส่พื้นที่ผิดเป็น $wH=6.0$ m$^{2}$ (ลืมตัวประกอบ $\frac12$ ของพื้นที่สามเหลี่ยม) ได้ $(1000)(10)\left(\frac23\right)(6.0)=40000$ N หรือเทียบเท่ากับการตั้ง $b(y)$ กลับด้าน (กว้าง 0 ที่ผิวน้ำ กว้างสุดที่ก้น) แล้วอินทิเกรตได้ $\rho g w H^{2}/3$ #พลาด/แทนค่า
trap: ตอบ $1.2\times10^{5}$ N — พลาดสองชั้นพร้อมกัน: ใช้ความดันที่ก้น $\rho gH=20000$ Pa คูณกับพื้นที่สี่เหลี่ยม $wH=6.0$ m$^{2}$ (ทั้งไม่ลดความดันเป็นค่าเฉลี่ย และทั้งลืมว่าประตูเป็นสามเหลี่ยมไม่ใช่สี่เหลี่ยม) ได้ $120000$ N ซึ่งเกินความจริงถึง 6 เท่า #พลาด/เงื่อนไข
trap: บวกความดันบรรยากาศเข้าไปด้วย ($p=P_0+\rho gy$) แล้วได้แรงมากกว่านี้มหาศาล — ผิดเพราะความดันบรรยากาศกระทำทั้งสองด้านของประตู (ด้านหน้าผ่านผิวน้ำลงมา และด้านหลังโดยตรง) จึงหักล้างกันหมด แรงลัพธ์บนประตูมาจากความดัน**เกจ**เท่านั้น ต่างจากโจทย์ที่ถาม "ความดัน ณ จุดหนึ่งในของเหลว" ซึ่งต้องบวก $P_0$ ถ้าถามความดันสัมบูรณ์ #พลาด/อ่านโจทย์
