# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2010
หัวข้อ: เสียง
หัวข้อย่อย: การสั่นพ้องในท่อปลายปิด
ระดับความยาก: 2
โจทย์: ปล่อยเสียงจากแหล่งกำเนิดที่ปรับความถี่ได้เข้าไปในท่อปลายปิด พบว่าความถี่ที่ทำให้เกิดการสั่นพ้อง เรียงจากน้อยไปมากคือ f_A, f_B, f_C, ... ถ้า f_B = 300 เฮิรตซ์ และอัตราเร็วเสียงในอากาศ 344 เมตรต่อวินาที ท่อนี้ยาวกี่เมตร
ตัวเลือก A: 0.29
ตัวเลือก B: 0.43
ตัวเลือก C: 0.57
ตัวเลือก D: 0.72
ตัวเลือก E: 0.86
คำตอบ: E
เฉลย: ท่อปลายปิดสั่นพ้องที่ฮาร์มอนิกคี่ f_n = n·v/(4L), n = 1, 3, 5, ... ความถี่ลำดับที่สอง f_B คือ n = 3 → 300 = 3×344/(4L) → L = 1032/1200 = 0.86 m
trap: ตอบ A — เข้าใจผิดว่า f_B คือความถี่มูลฐาน (n = 1)
trap: ตอบ C — ใช้สูตรท่อปลายเปิดสองด้าน (f_n = n·v/2L) โดยให้ n = 2
