# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1176
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: ดาวคู่สัดส่วนวงโคจร
ระดับความยาก: 3
โจทย์: ดาวสองดวงมวล $m$ และ $2m$ โคจรเป็นวงกลมรอบจุดศูนย์กลางมวลร่วมกัน โดยระยะห่างระหว่างดาวทั้งสองคงที่เท่ากับ $D$ ข้อใดกล่าวถูกต้องเกี่ยวกับวงโคจรของดาวทั้งสอง (กำหนด $G$ เป็นค่าคงที่โน้มถ่วงสากล)
ตัวเลือก A: รัศมีวงโคจรของดาวมวล $m$ ต่อดาวมวล $2m$ เป็น $2:1$ และทั้งสองมีคาบการโคจรเท่ากันคือ $T = 2\pi\sqrt{\dfrac{D^3}{3Gm}}$
ตัวเลือก B: รัศมีวงโคจรของดาวมวล $m$ ต่อดาวมวล $2m$ เป็น $1:2$ และทั้งสองมีคาบการโคจรเท่ากันคือ $T = 2\pi\sqrt{\dfrac{D^3}{3Gm}}$
ตัวเลือก C: รัศมีวงโคจรของดาวทั้งสองเท่ากัน แต่ดาวมวล $2m$ มีคาบมากกว่า $\sqrt{2}$ เท่า เพราะมวลมากกว่า
ตัวเลือก D: ดาวมวล $m$ โคจรรอบดาวมวล $2m$ ที่อยู่นิ่งเป็นศูนย์กลาง ด้วยคาบ $T = 2\pi\sqrt{\dfrac{D^3}{G(2m)}}$
ตัวเลือก E: รัศมีวงโคจรของดาวมวล $m$ ต่อดาวมวล $2m$ เป็น $4:1$ เพราะแรงโน้มถ่วงแปรผันกับมวลยกกำลังสอง
รูป: O-1176-binary-stars-ratio.png
รูปจำเป็น: ไม่
คำตอบ: A
เฉลย: ให้จุดศูนย์กลางมวลเป็นจุดอ้างอิง ดาวทั้งสองอยู่คนละข้างของจุดนี้เสมอ (มิฉะนั้นจุดศูนย์กลางมวลจะเคลื่อนที่) เงื่อนไข $m r_1 = (2m) r_2$ และ $r_1 + r_2 = D$ ได้ $r_1 = 2D/3$, $r_2 = D/3$ อัตราส่วน $2:1$ (ดาวเบากว่าวงกว้างกว่า) ทั้งสองกวาดมุมครบรอบพร้อมกันเสมอ คาบจึงเท่ากัน แรงโน้มถ่วง $Gm(2m)/D^2$ เป็นแรงสู่ศูนย์กลางของแต่ละดวง เช่นของดวง $m$: $\dfrac{Gm(2m)}{D^2} = m\omega^2r_1 = m\omega^2(2D/3)$ ได้ $\omega^2 = 3Gm/D^3$ ดังนั้น $T = 2\pi/\omega = 2\pi\sqrt{D^3/(3Gm)}$ (ตรวจซ้ำด้วยดวง $2m$: $G(2m)m/D^2 = (2m)\omega^2(D/3)$ ได้ $\omega$ ค่าเดียวกัน ยืนยันคาบเท่ากัน)
trap: ตอบ B — สลับอัตราส่วนรัศมีเป็น $1:2$ เข้าใจผิดว่าดาวที่หนักกว่าต้องวงกว้างกว่า (เหมือนดาวเคราะห์วงนอก) ทั้งที่จุดศูนย์กลางมวลต้องอยู่ใกล้ดาวหนักกว่า ดาวเบาจึงมีรัศมีวงโคจรกว้างกว่าเสมอ #พลาด/จุดศูนย์กลางมวล
trap: ตอบ C — ปฏิบัติเหมือนดาวเทียมโคจรรอบโลกที่คาบขึ้นกับรัศมีของแต่ละดวงแยกกัน ทั้งที่ดาวคู่ตรึงกันเป็นระบบวัตถุสองก้อนที่หมุนไปด้วยกัน (tidally locked เชิงมุม) คาบต้องเท่ากันเสมอเพราะอยู่บนเส้นตรงเดียวกันผ่านจุดศูนย์กลางมวลตลอดเวลา #พลาด/คอนเซปต์
trap: ตอบ D — ตรึงดาวมวล $2m$ ให้อยู่นิ่งเป็นศูนย์กลางแล้วใช้สูตรดาวเทียม $T = 2\pi\sqrt{D^3/GM}$ ตรงๆ ลืมว่าทั้งสองดวงเคลื่อนที่รอบจุดศูนย์กลางมวลร่วม ต้องใช้มวลรวม $M+m = 3m$ ไม่ใช่ $2m$ #พลาด/ดาวคู่
trap: ตอบ E — ยกกำลังสองอัตราส่วนมวลผิดๆ เป็น $4:1$ (สับสนกับกฎกำลังสองของระยะทางในกฎโน้มถ่วง) ทั้งที่เงื่อนไขจุดศูนย์กลางมวล $m_1r_1 = m_2r_2$ เป็นเชิงเส้น ไม่ใช่กำลังสอง #พลาด/สูตรผิด
