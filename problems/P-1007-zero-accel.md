# ที่มา: เทพฟิสิกส์ฯ (รัชพล/อมร) บทที่ 1 การเคลื่อนที่ในแนวเส้นตรง — external (รอตรวจคำตอบ)
id: P-1007
หัวข้อ: จลนศาสตร์
ระดับชั้น: ม.6
หัวข้อย่อย: ความเร่ง
ระดับความยาก: 2
โจทย์: การเคลื่อนที่ในข้อใดที่ความเร่งของวัตถุเป็นศูนย์
ตัวเลือก A: การเคลื่อนที่แบบวงกลมด้วยอัตราเร็วคงตัว
ตัวเลือก B: การไถลลงเป็นเส้นตรงบนพื้นเอียงลื่นที่ไม่มีแรงเสียดทาน
ตัวเลือก C: การเคลื่อนที่เป็นเส้นตรงในแนวระดับด้วยอัตราเร็วคงที่
ตัวเลือก D: การตกลงตรง ๆ ในแนวดิ่ง โดยไม่มีแรงต้านอากาศ
ตัวเลือก E: ไม่มีคำตอบที่ถูกต้อง
คำตอบ: C
เฉลย: ความเร่งเป็นศูนย์ = ความเร็ว (ทั้งขนาดและทิศ) ไม่เปลี่ยน มีเฉพาะข้อ C ที่ทั้งขนาดและทิศคงที่
trap: ตอบ A — วงกลมอัตราเร็วคงที่ ขนาดคงที่จริง แต่ทิศเปลี่ยนตลอด จึงยังมีความเร่งสู่ศูนย์กลาง #พลาด/นิยาม
trap: ตอบ D — ตกอิสระมีความเร่งจากแรงโน้มถ่วง (g) #พลาด/เงื่อนไข
