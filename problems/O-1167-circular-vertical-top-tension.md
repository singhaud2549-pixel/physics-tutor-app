# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1167
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: แรงตึงจุดสูงสุดวงดิ่ง
ระดับความยาก: 2
โจทย์: วัตถุมวล $3$ kg ผูกติดกับเชือกเบายาว $2.0$ m แล้วแกว่งเป็นวงกลมในระนาบดิ่ง ขณะวัตถุอยู่ที่ตำแหน่งสูงสุดของวงกลม อัตราเร็วของวัตถุคือ $6$ m/s จงหาแรงตึงเชือกที่ตำแหน่งนี้ (หน่วยนิวตัน กำหนด $g=10$ m/s$^2$)
รูป: O-1167.png
รูปจำเป็น: ไม่
หน่วย: นิวตัน (N)
คำตอบ: 24
คลาดเคลื่อน:
เฉลย: ที่ตำแหน่งสูงสุดของวงกลมแนวดิ่ง แรงลัพธ์ต้องพุ่งเข้าหาศูนย์กลางวงกลม (พุ่งลง) เพื่อทำหน้าที่เป็นแรงสู่ศูนย์กลาง แรงในแนวดิ่งมีสองแรงที่พุ่งลงทั้งคู่ คือแรงตึงเชือก $T$ (พุ่งลงเข้าหาศูนย์กลาง) และน้ำหนัก $mg$ (พุ่งลง) ให้ทิศพุ่งเข้าศูนย์กลาง (ลง) เป็นบวก: $T + mg = \dfrac{mv^2}{r}$ ดังนั้น $T = \dfrac{mv^2}{r} - mg = \dfrac{(3)(6)^2}{2.0} - (3)(10) = 54 - 30 = 24$ N (ตรวจอีกวิธี: แรงสู่ศูนย์กลางที่ต้องการคือ $mv^2/r = 54$ N น้ำหนักช่วยไปแล้ว $30$ N เชือกจึงต้องดึงเพิ่มอีก $54-30=24$ N และ $T>0$ จึงยังครบวงได้จริง)
trap: ตอบ 84 N — เผลอใช้สูตรของจุดต่ำสุด $T = mg + mv^2/r = 30+54$ โดยลืมว่าที่จุดสูงสุดน้ำหนัก $mg$ พุ่งเข้าหาศูนย์กลางอยู่แล้ว (ช่วยเป็นแรงสู่ศูนย์กลาง) จึงต้องลบออก ไม่ใช่บวกเพิ่ม #พลาด/แผนภาพแรง
trap: ตอบ 54 N — ลืมรวมน้ำหนัก $mg$ คิดว่าแรงตึงเชือกทำหน้าที่เป็นแรงสู่ศูนย์กลางเพียงอย่างเดียว ($T=mv^2/r$) โดยไม่ได้ลบน้ำหนักที่ช่วยพุ่งเข้าศูนย์กลางที่จุดสูงสุด #พลาด/แผนภาพแรง
trap: ตอบ 39 N — คำนวณแรงสู่ศูนย์กลางผิดโดยลืมยกกำลังสองความเร็ว ใช้ $mv/r$ แทน $mv^2/r$ ได้ $T = mg + mv/r = 30 + (3)(6)/2.0 = 30+9 = 39$ N ซึ่งผิดสูตร (และยังบวกผิดทิศอีกด้วย) #พลาด/สูตรผิด
trap: ตอบ 30 N — เข้าใจผิดว่าแรงตึงเชือกที่จุดสูงสุดเท่ากับน้ำหนักพอดี ($T=mg$) เหมือนวัตถุห้อยนิ่ง โดยลืมว่าวัตถุยังเคลื่อนที่เป็นวงกลมอยู่ ต้องมีแรงลัพธ์สุทธิพุ่งเข้าศูนย์กลาง ($T+mg=mv^2/r \ne 0$) #พลาด/แผนภาพแรง
