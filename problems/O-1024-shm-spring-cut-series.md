# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1024
หัวข้อ: การเคลื่อนที่ฮาร์มอนิก (SHM)
หัวข้อย่อย: ตัดสปริงแล้วต่ออนุกรมกลับ ผลต่อค่านิจสปริงรวมและคาบการแกว่ง
ระดับความยาก: 4
โจทย์: สปริงเส้นหนึ่งมีค่านิจสปริง $k=200$ N/m ถูกตัดออกเป็น $2$ ท่อนเท่ากันทุกประการ จากนั้นนำสปริงสองท่อนที่ตัดได้มาต่อกันแบบอนุกรม (เชื่อมปลายต่อปลายเรียงกันเป็นเส้นตรงเหมือนความยาวเดิม) แล้วนำมวล $2$ kg มาติดปลายสปริงที่ต่อกันนี้บนพื้นราบลื่น ดึงให้แกว่งในแนวราบ จงหาคาบการแกว่ง (หน่วยวินาที)
หน่วย: วินาที (s)
คำตอบ: 0.628
คลาดเคลื่อน: 0.02
เฉลย: เมื่อตัดสปริงเส้นหนึ่งออกเป็นท่อนสั้นลงเท่าๆ กัน ค่านิจสปริงของแต่ละท่อนจะ**แปรผกผัน**กับความยาวของท่อนนั้น (ท่อนสั้นกว่า = แข็งกว่า = ค่านิจมากกว่า) เมื่อตัดเป็น $2$ ท่อนเท่ากัน แต่ละท่อนจะมีความยาวครึ่งหนึ่งของเดิม ดังนั้นแต่ละท่อนมีค่านิจ $k' = 2k = 2(200)=400$ N/m. เมื่อนำสปริงสองท่อนนี้มาต่อแบบอนุกรม ค่านิจรวมคำนวณจาก $\dfrac{1}{k_{eq}}=\dfrac{1}{k'}+\dfrac{1}{k'}=\dfrac{2}{400}=\dfrac{1}{200} \Rightarrow k_{eq}=200$ N/m (ค่านิจรวมกลับมาเท่ากับค่านิจสปริงเส้นเดิมพอดี เพราะการตัดแล้วต่ออนุกรมกลับเป็นความยาวเท่าเดิม เสมือนได้สปริงเส้นเดิมกลับคืนมา) คาบการแกว่งคือ $T=2\pi\sqrt{\dfrac{m}{k_{eq}}} = 2\pi\sqrt{\dfrac{2}{200}} = 2\pi\sqrt{0.01} = 2\pi(0.1) \approx 0.628$ s
trap: ตอบ 0.44 s — คิดว่าเมื่อตัดสปริงเป็นสองท่อนแล้วนำมาต่ออนุกรมกันใหม่ จะได้ระบบที่แข็งขึ้นกว่าสปริงเดิม (นำค่านิจของสปริงท่อนเดียวหลังตัด $k'=400$ N/m มาใช้คำนวณคาบตรงๆ โดยลืมว่าต้องต่ออนุกรมกับอีกท่อนหนึ่งก่อน) ได้ $T=2\pi\sqrt{2/400}\approx0.44$ s ซึ่งไม่ถูกต้อง เพราะการต่ออนุกรมทำให้ค่านิจรวมลดลงจาก 400 กลับมาเป็น 200 #พลาด/เงื่อนไข #trap/88
trap: ตอบ 0.89 s — ลืมว่าการตัดสปริงให้สั้นลงทำให้ค่านิจของแต่ละท่อนเพิ่มขึ้นเป็น 2 เท่า (ยังคงคิดว่าแต่ละท่อนมีค่านิจเท่าเดิมคือ $k=200$ N/m ทั้งสองท่อน) แล้วนำไปต่ออนุกรมกันตามสูตร ได้ค่านิจรวมผิดเป็น $k_{eq}=100$ N/m ($1/k_{eq}=1/200+1/200$) คำนวณคาบได้ $T=2\pi\sqrt{2/100}\approx0.89$ s ซึ่งผิดตั้งแต่ขั้นตอนแรก #พลาด/เงื่อนไข #trap/88
trap: ตอบ 0.10 s — จำสูตรคาบผิดโดยลืมตัวคูณ $2\pi$ ใช้ $T=\sqrt{m/k_{eq}}=\sqrt{2/200}=0.1$ s ตรงๆ โดยไม่คูณด้วย $2\pi$ ตามสูตรที่ถูกต้อง #พลาด/สูตรผิด
