# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1095
หัวข้อ: ของแข็ง
หัวข้อย่อย: พลังงานศักย์ยืดหยุ่นจากแรงที่ไม่เป็นไปตามกฎของฮุก (non-Hookean) หางานจากการอินทิเกรต F dx
ระดับความยาก: 5
โจทย์: แท่งวัสดุชนิดหนึ่งแสดงพฤติกรรมยืดหยุ่นแบบไม่เป็นไปตามกฎของฮุก (non-Hookean) ตลอดช่วงที่พิจารณา คือแรงดึงที่ต้องใช้ $F(x)$ (หน่วยนิวตัน) เพื่อทำให้แท่งวัสดุยืดออกจากความยาวธรรมชาติเป็นระยะ $x$ (หน่วยเมตร) เขียนเป็นฟังก์ชันได้ว่า $F(x)=kx+bx^3$ โดย $k=200$ N/m และ $b=800$ N/m$^3$ (ตลอดช่วงนี้ยังถือว่าเป็นการเปลี่ยนรูปแบบยืดหยุ่นเต็มที่ คือคืนตัวกลับได้สมบูรณ์เมื่อปล่อยแรง เพียงแต่ความสัมพันธ์ระหว่างแรงกับระยะยืดไม่ใช่เส้นตรง) ถ้าดึงแท่งวัสดุนี้อย่างช้าๆ (quasi-static) จากสภาพธรรมชาติจนยืดออกเป็นระยะ $x_1=0.5$ m จงหาพลังงานศักย์ยืดหยุ่นที่สะสมอยู่ในแท่งวัสดุ ณ ขณะนั้น
หน่วย: จูล (J)
คำตอบ: 37.5
คลาดเคลื่อน: 0.5
เฉลย: เนื่องจากแรง $F(x)$ ไม่คงที่และไม่แปรผันตรงกับ $x$ (มีพจน์ $bx^3$ ซึ่งไม่เป็นเชิงเส้น) จึงใช้สูตรพลังงานศักย์สปริงแบบฮุกทั่วไป $U=\frac12kx^2$ ตรงๆ ไม่ได้ ต้องคำนวณจากนิยามงาน = อินทิเกรตของแรงตามระยะทางที่เคลื่อนที่: $U=W=\displaystyle\int_0^{x_1}F(x)\,dx=\int_0^{x_1}(kx+bx^3)\,dx=\left[\dfrac12kx^2+\dfrac14bx^4\right]_0^{x_1}$ แทนค่า $k=200$, $b=800$, $x_1=0.5$: พจน์แรก $\dfrac12(200)(0.5)^2=\dfrac12(200)(0.25)=25$ J พจน์ที่สอง $\dfrac14(800)(0.5)^4=\dfrac14(800)(0.0625)=12.5$ J รวมเป็น $U=25+12.5=37.5$ J (ตรวจสอบอีกวิธี — คำนวณแรงที่ปลายทาง $F(x_1)=200(0.5)+800(0.5)^3=100+100=200$ N แล้วประมาณพื้นที่ใต้กราฟ $F$-$x$ ด้วยกฎของซิมป์สัน (Simpson's rule) โดยใช้ 3 จุด $x=0,0.25,0.5$: $F(0)=0$, $F(0.25)=200(0.25)+800(0.25)^3=50+12.5=62.5$ N, $F(0.5)=200$ N ได้ $U\approx\dfrac{0.5}{6}\left[F(0)+4F(0.25)+F(0.5)\right]=\dfrac{0.5}{6}[0+250+200]=\dfrac{0.5}{6}(450)=37.5$ J ตรงกับคำตอบจากการอินทิเกรตพอดี เพราะกฎของซิมป์สันให้ผลแม่นยำสำหรับฟังก์ชันพหุนามกำลังไม่เกิน 3 อยู่แล้ว)
trap: ตอบ 100 — เข้าใจผิดคิดว่างาน = แรง(คงที่)×ระยะทาง โดยใช้แรงที่ปลายทาง $F(x_1)=200$ N คูณกับระยะยืด $x_1=0.5$ m ตรงๆ ($W=F(x_1)\cdot x_1=200\times0.5=100$ J) โดยไม่ได้อินทิเกรตเลย ลืมว่าแรงเปลี่ยนแปลงตลอดการยืด ไม่ใช่คงที่เท่ากับค่าสุดท้าย
trap: ตอบ 25 — ใช้สูตรพลังงานศักย์สปริงฮุกแบบเส้นตรงปกติ $U=\frac12kx_1^2$ อย่างเดียว ลืมพจน์ไม่เชิงเส้น $bx^3$ ไปเลย (มองข้ามว่าพจน์นี้ก็มีส่วนสะสมพลังงานด้วย) ทำให้ตกหล่นพลังงานจากพจน์ไม่เชิงเส้นไป 12.5 J
trap: ตอบ 50 — สมมติผิดว่าแรงแปรผันเป็นเส้นตรงจาก 0 ถึง $F(x_1)=200$ N ตลอดการยืด (เหมือนกรณีสปริงฮุกทั่วไปที่กราฟ F-x เป็นเส้นตรง) แล้วคิดพื้นที่ใต้กราฟเป็นรูปสามเหลี่ยม $U=\frac12F(x_1)x_1=\frac12(200)(0.5)=50$ J โดยไม่ทันสังเกตว่ากราฟจริงเป็นเส้นโค้ง (ผลจากพจน์ $bx^3$) ไม่ใช่เส้นตรง
trap: ตอบ 75 — อินทิเกรตพจน์ $bx^3$ ผิด ลืมหารด้วย 4 (จำสูตร $\int x^3\,dx=x^4$ แทนที่จะเป็น $\frac{x^4}{4}$) ทำให้ได้ $U=\frac12(200)(0.25)+800(0.0625)=25+50=75$ J
