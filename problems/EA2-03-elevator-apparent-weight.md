# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · ข้อสอบจำลอง A-Level ชุดที่ 2

หัวข้อ: แรงและกฎนิวตัน
ระดับชั้น: ม.6
หัวข้อย่อย: ระบบวัตถุหลายก้อน และน้ำหนักปรากฏ
ระดับความยาก: 2
ชุดข้อสอบ: MOCK-ALEVEL-2
ลำดับ: 3
คะแนน: 3
trap-ids: 159
โจทย์: ชายคนหนึ่งมวล 50.0 กิโลกรัม ยืนอยู่บนตาชั่งสปริงในลิฟต์ ขณะหนึ่งลิฟต์กำลังเคลื่อนที่โดยมีความเร่งขนาด 2.0 เมตรต่อวินาที$^2$ ในทิศขึ้น
กำหนดให้: ความเร่งโน้มถ่วงของโลกเท่ากับ 9.8 เมตรต่อวินาที$^2$
คำถาม: ตาชั่งสปริงอ่านค่าได้กี่นิวตัน
ตัวเลือก A: $390$
ตัวเลือก B: $490$
ตัวเลือก C: $500$
ตัวเลือก D: $590$
ตัวเลือก E: $600$
คำตอบ: D
เฉลย: ตาชั่งอ่านค่าแรงตั้งฉาก $N$ ที่ตาชั่งดันชายคนนี้

เขียนกฎข้อที่สองของนิวตันในแนวดิ่ง โดยให้ทิศขึ้น (ทิศเดียวกับความเร่ง) เป็นบวก:

$N-mg=ma \Rightarrow N=m(g+a)=50.0(9.8+2.0)=50.0(11.8)=590$ นิวตัน
trap: ตอบ $390$ — ใส่เครื่องหมายความเร่งผิดเป็น $N=m(g-a)=50.0(7.8)=390$ เข้าใจผิดว่าลิฟต์เร่งขึ้นแล้วน้ำหนักปรากฏต้องลดลง (ที่จริงลดลงเมื่อความเร่งมีทิศ *ลง*) #พลาด/ทิศ #trap/159
trap: ตอบ $490$ — ลืมคิดความเร่งไปเลย ตอบน้ำหนักจริง $mg=50.0(9.8)=490$ N (เป็นค่าที่ถูกเฉพาะตอนลิฟต์นิ่งหรือเคลื่อนที่ด้วยความเร็วคงตัว) #พลาด/แผนภาพแรง #trap/159
trap: ตอบ $500$ — ลืมความเร่ง **และ** ใช้ $g=10$ แทน $9.8$ : $50.0(10)=500$ N #พลาด/แทนค่า #trap/159
trap: ตอบ $600$ — ตั้งสมการถูกทุกอย่างแต่ใช้ $g=10$ แทนค่าจริง $9.8$ ที่โจทย์กำหนด: $50.0(10+2.0)=600$ N #พลาด/แทนค่า
