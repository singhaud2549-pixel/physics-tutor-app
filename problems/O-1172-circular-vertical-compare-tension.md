# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1172
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: เปรียบเทียบแรงตึงสามตำแหน่ง
ระดับความยาก: 4
โจทย์: ก้อนหินมวล $2$ kg ผูกเชือกเบายาว $0.5$ m แกว่งเป็นวงกลมในระนาบดิ่ง โดยที่จุดต่ำสุดของวง (ตำแหน่งที่ 1) ก้อนหินมีอัตราเร็ว $6$ m/s จากนั้นก้อนหินเคลื่อนขึ้นผ่านตำแหน่งด้านข้าง (ตำแหน่งที่ 2 ระดับเดียวกับศูนย์กลาง) จนถึงจุดสูงสุดของวง (ตำแหน่งที่ 3) ให้ $T_1, T_2, T_3$ เป็นแรงตึงเชือกที่ตำแหน่งที่ 1, 2, 3 ตามลำดับ ข้อใดถูกต้อง (กำหนด $g=10$ m/s$^2$)
ตัวเลือก A: $T_1 > T_2 > T_3$ โดย $T_1 = 164$ N, $T_2 = 104$ N, $T_3 = 44$ N
ตัวเลือก B: $T_1 > T_2 > T_3$ โดย $T_1 = 92$ N, $T_2 = 52$ N, $T_3 = 12$ N
ตัวเลือก C: $T_3 > T_2 > T_1$ โดย $T_3 = 164$ N, $T_2 = 104$ N, $T_1 = 44$ N
ตัวเลือก D: $T_1 = T_2 > T_3$ โดย $T_1 = T_2 = 124$ N, $T_3 = 84$ N
ตัวเลือก E: $T_1 = T_2 = T_3$ เพราะเป็นการเคลื่อนที่เป็นวงกลมเหมือนกัน

รูปจำเป็น: ไม่
คำตอบ: A
เฉลย: หาอัตราเร็วแต่ละตำแหน่งด้วยพลังงานก่อน จากจุดต่ำสุดขึ้นไปสูง $L=0.5$ m (ตำแหน่งที่ 2): $v_2^2 = v_1^2 - 2gL = 36 - 10 = 26$ และขึ้นไปสูง $2L = 1.0$ m (ตำแหน่งที่ 3): $v_3^2 = v_1^2 - 2g(2L) = 36 - 20 = 16$. แล้ววิเคราะห์แรงสู่ศูนย์กลาง: ตำแหน่งที่ 1 (ล่าง) $T_1 - mg = mv_1^2/L$ ได้ $T_1 = 20 + (2)(36)/0.5 = 20+144 = 164$ N ตำแหน่งที่ 2 (ข้าง) $T_2 = mv_2^2/L = (2)(26)/0.5 = 104$ N ตำแหน่งที่ 3 (บน) $T_3 + mg = mv_3^2/L$ ได้ $T_3 = (2)(16)/0.5 - 20 = 64-20 = 44$ N จึงได้ $T_1 > T_2 > T_3$ คือ $164 > 104 > 44$ N (ตรวจอีกวิธี: แรงสู่ศูนย์กลางที่ต้องการแต่ละจุดคือ $144, 104, 64$ N ตามลำดับ ที่จุดล่างน้ำหนักต้าน ($164 = 144+20$) จุดข้างน้ำหนักไม่เกี่ยว ($104$) จุดบนน้ำหนักช่วย ($44 = 64-20$) ลำดับจึงลดหลั่นตามนี้)
trap: ตอบ B — ลำดับถูกแต่ตัวเลขผิดเพราะใช้เส้นผ่านศูนย์กลาง $d = 1.0$ m แทนรัศมี $r = 0.5$ m ในสูตร $mv^2/r$ ได้ $T_1 = 20+72 = 92$, $T_2 = 52$, $T_3 = 32-20 = 12$ N (ความยาวเชือกคือรัศมีโดยตรง ไม่ต้องคูณสอง) #พลาด/อ่านโจทย์
trap: ตอบ C — สลับลำดับขั้วเป็น $T_3 > T_2 > T_1$ โดยเข้าใจผิดว่ายิ่งสูงยิ่งต้องดึงเชือกแรงขึ้น ทั้งที่ยิ่งสูงอัตราเร็วยิ่งลดลงและน้ำหนักยิ่งช่วยเป็นแรงสู่ศูนย์กลาง แรงตึงจึงยิ่งน้อยลง #พลาด/แผนภาพแรง
trap: ตอบ D — สลับเครื่องหมาย $mg$ ที่จุดล่างกับจุดข้าง ใช้ $T_1 = mv^2/L - mg = 124$ กับ $T_2 = mv^2/L + mg = 124$ และ $T_3 = mv^2/L + mg = 84$ ได้ $T_1 = T_2 > T_3$ ทั้งที่จุดล่างน้ำหนักต้าน (ต้องบวก) จุดข้างน้ำหนักไม่เกี่ยว จุดบนน้ำหนักช่วย (ต้องลบ) #พลาด/แผนภาพแรง
trap: ตอบ E — เข้าใจผิดว่าแรงตึงเชือกคงที่ตลอดวงเพราะ "เป็นการเคลื่อนที่แบบวงกลมเหมือนกัน" สับสนกับวงกลมระดับที่อัตราเร็วคงที่ ทั้งที่วงดิ่งอัตราเร็วเปลี่ยนตามความสูงและทิศของน้ำหนักเทียบศูนย์กลางก็เปลี่ยนไปด้วย #พลาด/เงื่อนไข
