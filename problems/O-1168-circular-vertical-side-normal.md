# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1168
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: จุดด้านข้างวงดิ่ง
ระดับความยาก: 2
โจทย์: ลูกปัดมวล $2$ kg ไถลบนรางวงกลมลื่นในระนาบดิ่ง รัศมี $1.0$ m ขณะลูกปัดอยู่ที่ตำแหน่งด้านข้างของวงกลม (ระดับเดียวกับศูนย์กลางวงกลมพอดี) อัตราเร็วของลูกปัดคือ $4$ m/s จงหาแรงปฏิกิริยาที่รางกระทำต่อลูกปัด (แรงตั้งฉาก $N$) ที่ตำแหน่งนี้
ตัวเลือก A: 52 N
ตัวเลือก B: 12 N
ตัวเลือก C: 32 N
ตัวเลือก D: 20 N
ตัวเลือก E: 8 N
รูป: O-1168.png
รูปจำเป็น: ไม่
คำตอบ: C
เฉลย: ที่ตำแหน่งด้านข้าง ทิศพุ่งเข้าหาศูนย์กลางวงกลมคือทิศแนวระดับ แรงเดียวที่มีองค์ประกอบในทิศนี้คือแรงปฏิกิริยาตั้งฉาก $N$ จากราง (พุ่งเข้าศูนย์กลาง) ส่วนน้ำหนัก $mg$ พุ่งลงในแนวดิ่งซึ่งตั้งฉากกับทิศรัศมี จึงไม่เกี่ยวเลย ให้ทิศเข้าศูนย์กลางเป็นบวก: $N = \dfrac{mv^2}{r} = \dfrac{(2)(4)^2}{1.0} = 32$ N (ตรวจอีกวิธี: แรงสู่ศูนย์กลางที่ต้องการคือ $mv^2/r = 32$ N และมีเพียง $N$ แรงเดียวที่ชี้เข้าศูนย์กลาง ดังนั้น $N$ ต้องเท่ากับ $32$ N พอดี)
trap: ตอบ 52 N — เอาน้ำหนัก $mg=20$ N ไปบวกเพิ่มผิดๆ ($N = mg + mv^2/r$) โดยลืมว่าน้ำหนักพุ่งในแนวดิ่ง ตั้งฉากกับทิศเข้าศูนย์กลาง (แนวระดับ) ที่จุดด้านข้าง จึงไม่มีส่วนในสมการแรงสู่ศูนย์กลางเลย #พลาด/แผนภาพแรง
trap: ตอบ 12 N — เอาน้ำหนักไปลบผิดๆ ($N = mv^2/r - mg = 32-20$) สับสนกับสูตรจุดสูงสุดของวงดิ่ง ทั้งที่จุดด้านข้างน้ำหนักไม่ได้อยู่ในทิศรัศมีเลย ไม่ต้องบวกหรือลบทั้งสิ้น #พลาด/แผนภาพแรง
trap: ตอบ 20 N — ตอบเพียงน้ำหนัก $mg=20$ N โดยเข้าใจผิดว่าแรงที่รางกระทำมีค่าเท่าน้ำหนักเสมอ ลืมว่าวัตถุเคลื่อนที่เป็นวงกลมอยู่ ต้องมีแรงลัพธ์พุ่งเข้าศูนย์กลาง $mv^2/r \ne 0$ #พลาด/แผนภาพแรง
trap: ตอบ 8 N — คำนวณแรงสู่ศูนย์กลางผิดโดยลืมยกกำลังสองความเร็ว ใช้ $mv/r = (2)(4)/1.0 = 8$ N แทน $mv^2/r$ ซึ่งผิดสูตร #พลาด/สูตรผิด
