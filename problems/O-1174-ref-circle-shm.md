# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1174
หัวข้อ: การเคลื่อนที่แบบวงกลม
หัวข้อย่อย: วงกลมอ้างอิงกับ SHM
ระดับความยาก: 2
โจทย์: หมุดเล็กติดอยู่บนขอบจานหมุนราบซึ่งหมุนสม่ำเสมอด้วยคาบ $4$ s มีฉากรับเงาวางขนานกับเส้นผ่านศูนย์กลางของจาน และฉายแสงขนานตั้งฉากกับฉาก ทำให้เงาของหมุดบนฉากเคลื่อนที่กลับไปกลับมาแบบฮาร์มอนิกอย่างง่าย (SHM) ข้อใดระบุคาบและความถี่ของการเคลื่อนที่แบบ SHM ของเงาได้ถูกต้อง
ตัวเลือก A: คาบ $2$ s ความถี่ $0.5$ Hz
ตัวเลือก B: คาบ $4$ s ความถี่ $4$ Hz
ตัวเลือก C: คาบ $4$ s ความถี่ $0.25$ Hz
ตัวเลือก D: คาบ $8$ s ความถี่ $0.125$ Hz
ตัวเลือก E: คาบ $2$ s ความถี่ $2$ Hz
รูป: O-1174-ref-circle-shm.png
รูปจำเป็น: ไม่
คำตอบ: C
เฉลย: เงาของหมุดบนฉากคือภาพฉายของตำแหน่งหมุดบนเส้นผ่านศูนย์กลาง $x = A\cos(\omega t + \phi_0)$ ซึ่งครบ 1 รอบการสั่นพอดีเมื่อหมุดหมุนครบ 1 รอบวงกลม ดังนั้นคาบของ SHM เท่ากับคาบการหมุนตรงๆ $T = 4$ s (ไม่ครึ่ง ไม่สองเท่า) และความถี่ $f = 1/T = 1/4 = 0.25$ Hz (ตรวจสอบอีกวิธี: $\omega = 2\pi/T = \pi/2$ rad/s แล้ว $f=\omega/2\pi = 0.25$ Hz ตรงกัน)
trap: ตอบ A — เข้าใจผิดว่าเงา "ไปสุดข้างหนึ่งแล้วกลับ" นับเป็น 1 รอบ ทำให้ได้คาบครึ่งเดียวของรอบวงกลม ($T=2$ s, $f=0.5$ Hz) ทั้งที่การกระจัด $x=A\cos\theta$ ต้องรอ $\theta$ ครบ $2\pi$ จึงจะกลับค่าเดิม #พลาด/SHM-วงกลมอ้างอิง
trap: ตอบ B — จำสูตรสลับกัน ใช้ $f = T$ แทน $f = 1/T$ ได้ความถี่ $4$ Hz ทั้งที่มิติของความถี่ต้องเป็นส่วนกลับของเวลา #พลาด/สูตรผิด
trap: ตอบ D — เข้าใจผิดว่าต้องหมุน 2 รอบเงาจึงจะกลับมาตำแหน่งเดิม (สับสนกับความถี่เชิงมุม $\omega$ กับความถี่ $f$) ได้คาบ $8$ s #พลาด/SHM-วงกลมอ้างอิง
trap: ตอบ E — ทำสองขั้นผิดพร้อมกัน (คาบครึ่งเดียว $T=2$ s แล้วยังใช้ $f=T$ อีก) ได้ $f=2$ Hz #พลาด/สูตรผิด
