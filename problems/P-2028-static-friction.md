# ที่มา: หนังสือ (external, สกัดผ่าน Gemini) — ใช้ทดสอบฟรีเท่านั้น รอทำต้นฉบับก่อนขาย
id: P-2028
หัวข้อ: สมดุลและโมเมนต์
หัวข้อย่อย: แรงเสียดทานสถิต
ระดับความยาก: 3
โจทย์: จากรูป มวล $m_1 = 5$ kg วางบนพื้นราบมีความเสียดทาน ผูกเชือกแนวนอนไปที่ปม ส่วนมวล $m_2 = 8$ kg วางบนพื้นเอียงลื่นมุม 45° ผูกเชือกขนานพื้นเอียงไปที่ปมเดียวกัน ปมถูกแขวนกับเพดานด้วยเชือกแนวดิ่ง ทั้งระบบอยู่นิ่ง จงหาสัมประสิทธิ์แรงเสียดทานสถิตระหว่าง $m_1$ กับพื้นราบ อย่างน้อยเท่าใด (ตอบเป็นตัวเลข)
รูป: P-2028-equilibrium.png
รูปจำเป็น: ใช่
คำตอบ: 0.80
คลาดเคลื่อน: 0.02
เฉลย: $m_2$ บนพื้นเอียงลื่น 45°: แรงตึงขนานพื้นเอียง $T_2 = m_2 g\sin45^\circ = \frac{8g}{\sqrt{2}}$. ที่ปม สมดุลแนวนอน: $T_1 = T_2\cos45^\circ = \frac{8g}{\sqrt{2}}\cdot\frac{1}{\sqrt{2}} = 4g$. สำหรับ $m_1$: $\mu_s m_1 g \ge T_1$ → $\mu_s(5g) \ge 4g$ → $\mu_s \ge 0.80$
