# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · แนวสอบเข้ามหาลัย
id: O-1130
หัวข้อ: แสงและทัศนศาสตร์
ระดับชั้น: ม.ต้น
หัวข้อย่อย: กระจกเงาราบสองบานทำมุมกัน — ไล่มุมด้วยผลรวมมุมในสามเหลี่ยม
ระดับความยาก: 3
โจทย์: กระจกเงาราบสองบานคือ $M_1$ และ $M_2$ วางตั้งทำมุมกัน $70°$ โดยขอบของทั้งสองบานจรดกันที่จุด $O$ และหันด้านสะท้อนเข้าหากันดังรูป ลำแสงเส้นหนึ่งพุ่งเข้ามาในบริเวณระหว่างกระจกทั้งสอง ตกกระทบกระจก $M_1$ ที่จุด $P$ ด้วย**มุมตกกระทบ $30°$** (วัดจากเส้นแนวฉากของ $M_1$) ลำแสงที่สะท้อนจาก $P$ เดินทางไปตกกระทบกระจก $M_2$ ที่จุด $Q$ จงหา**มุมตกกระทบที่จุด $Q$** (วัดจากเส้นแนวฉากของ $M_2$)
รูป: O-1130-two-mirrors.png
รูปจำเป็น: ใช่
ตัวเลือก A: 30°
ตัวเลือก B: 35°
ตัวเลือก C: 40°
ตัวเลือก D: 50°
ตัวเลือก E: 60°
คำตอบ: C
เฉลย: **⚠️ คำสั่งถึงผู้ใบ้: นักเรียนข้อนี้เป็น ม.ต้น — ใบ้ด้วยการไล่มุมในสามเหลี่ยมเท่านั้น ห้ามใช้ sin/cos/tan/arctan หรือระบบพิกัดในการใบ้เด็ดขาด (ส่วน "ตรวจสอบวิธีที่ 2" ท้ายเฉลยมีไว้ยืนยันความถูกต้องของเลขเท่านั้น ห้ามหยิบไปใบ้)** **แนวคิดหลัก — ข้อนี้ไม่มีสูตรฟิสิกส์อะไรเลยนอกจาก "มุมตกกระทบ = มุมสะท้อน" ที่เหลือคือการไล่มุมในสามเหลี่ยม $OPQ$ กุญแจคือต้องสลับไปมาระหว่าง "มุมที่วัดจากเส้นแนวฉาก" กับ "มุมที่วัดจากผิวกระจก" ให้คล่อง (สองอย่างนี้บวกกันได้ $90°$ เสมอ เพราะเส้นแนวฉากตั้งฉากกับผิวกระจก)** **ขั้นที่ 1 หามุมที่จุด $P$ ในสามเหลี่ยม.** ที่ $P$ มุมตกกระทบ $= 30°$ ⇒ มุมสะท้อน $= 30°$ ด้วย (วัดจากเส้นแนวฉากของ $M_1$) ⇒ รังสีสะท้อน $PQ$ ทำมุมกับ**ผิวกระจก $M_1$** เท่ากับ $90° - 30° = 60°$ เนื่องจากจุด $O$ อยู่บนผิวของ $M_1$ มุมนี้ก็คือ **มุม $OPQ = 60°$** **ขั้นที่ 2 ใช้ผลรวมมุมภายในสามเหลี่ยม $OPQ$.** จุดยอดทั้งสามคือ $O$ (จุดที่กระจกสองบานบรรจบกัน), $P$ (บน $M_1$) และ $Q$ (บน $M_2$) ⇒ ด้าน $OP$ วางอยู่บนผิว $M_1$ และด้าน $OQ$ วางอยู่บนผิว $M_2$ ⇒ **มุม $POQ =$ มุมระหว่างกระจกสองบาน $= 70°$** ดังนั้น มุม $OQP = 180° - 70° - 60° = 50°$ **ขั้นที่ 3 แปลงกลับเป็นมุมจากเส้นแนวฉากของ $M_2$.** มุม $OQP = 50°$ คือมุมที่รังสี $QP$ ทำกับ**ผิวกระจก $M_2$** ⇒ มุมตกกระทบที่ $Q$ (วัดจาก**เส้นแนวฉาก**ของ $M_2$) $= 90° - 50° = \mathbf{40°}$ **ตรวจสอบวิธีที่ 1 (กฎลัดที่พิสูจน์ได้จากขั้นที่ 1–3 เอง).** จากผลรวมมุมในสามเหลี่ยม: $(90° - i_1) + (90° - i_2) + \alpha = 180°$ ⇒ $\boxed{i_1 + i_2 = \alpha}$ เมื่อ $\alpha$ คือมุมระหว่างกระจก ตรวจกับตัวเลขในข้อนี้: $30° + 40° = 70° = \alpha$ ✓ **ตรวจสอบวิธีที่ 2 (พิกัดจริง อิสระจากการไล่มุม).** ให้ $O = (0,0)$, $M_1$ วางบนแกน $x$, $M_2$ วางบนเส้นที่ทำมุม $70°$ กับแกน $x$ และให้ $P = (6,\,0)$ รังสีสะท้อนจาก $P$ มีทิศ $(-\sin 30°,\, \cos 30°) = (-0.5,\, 0.866)$ หาจุดตัดกับเส้น $M_2$ ได้ $Q \approx (2.320,\, 6.374)$ ตรวจว่า $Q$ อยู่บน $M_2$ จริง: $\arctan\!\left(\dfrac{6.374}{2.320}\right) = 70.0°$ ✓ จากนั้นคำนวณมุมระหว่างรังสี $QP$ กับเส้นแนวฉากของ $M_2$ ได้ $40.0°$ พอดี ✓ (ตรวจต่อได้อีกชั้น: รังสีที่**เข้ามา**มีทิศ $240°$ เทียบแกน $x$ ส่วนรังสีที่**ออกจาก** $Q$ มีทิศ $20°$ ⇒ มุมระหว่างทิศเข้ากับทิศออก $= 140° = 2\alpha$ พอดี ตรงกับกฎมุมเบนรวมของกระจกสองบาน $360° - 2\alpha = 220°$ เมื่อวัดการหมุนไปอีกทาง — กรณีพิเศษ $\alpha = 90°$ จะได้ $2\alpha = 180°$ คือลำแสงย้อนกลับขนานกับทางเดิม ซึ่งเป็นผลที่คุ้นเคยของมุมสะท้อนกลับ) **ตอบ 40° (ข้อ C)**
trap: ตอบ 30° — คิดว่ามุมตกกระทบที่กระจกบานที่สอง**ต้องเท่ากับ**บานแรก โดยลาก "มุมตกกระทบ = มุมสะท้อน" ข้ามไปใช้กับกระจกคนละบาน ทั้งที่กฎนี้ใช้ได้เฉพาะ**ที่จุดสะท้อนจุดเดียวกันบนกระจกบานเดียวกัน**เท่านั้น เพราะเส้นแนวฉากของกระจกสองบานไม่ขนานกัน (จะเท่ากันก็ต่อเมื่อกระจกขนานกัน คือ $\alpha = 0$) ในข้อนี้ $i_1 + i_2$ ต้องเท่ากับ $70°$ จึงเป็น $30°$ ทั้งคู่ไม่ได้ #พลาด/เงื่อนไข
trap: ตอบ 50° — ไล่มุมในสามเหลี่ยม $OPQ$ ได้ถูกหมดแล้ว (ได้มุม $OQP = 50°$) แต่ตอบเลขนี้ทันที **ลืมว่านั่นคือมุมที่วัดจากผิวกระจก** ไม่ใช่จากเส้นแนวฉาก ต้องเอา $90°$ ลบก่อนจึงจะเป็น "มุมตกกระทบ" ตามนิยาม — เป็นความพลาดที่พบบ่อยที่สุดของโจทย์กระจกเชิงเรขาคณิต #พลาด/นิยาม
trap: ตอบ 60° — หยิบมุม $OPQ = 90° - 30° = 60°$ (มุมที่รังสีทำกับผิวกระจกบานแรก) มาตอบ คือคำนวณถูกแต่ตอบมุมผิดจุด (มุมที่ $P$ แทนมุมที่ $Q$) และยังเป็นมุมที่วัดจากผิวกระจกอีกด้วย ผิดสองชั้น #พลาด/อ่านโจทย์
trap: ตอบ 35° — เดาว่ามุมตกกระทบที่บานที่สองเป็นครึ่งหนึ่งของมุมระหว่างกระจก ($70°/2 = 35°$) โดยไม่ไล่มุมจริง — ค่านี้ถูกก็ต่อเมื่อ $i_1 = i_2 = \alpha/2$ พอดี (กรณีลำแสงเดินสมมาตร) แต่ข้อนี้ $i_1 = 30° \ne 35°$ ความสัมพันธ์ที่ใช้ได้เสมอคือ $i_1 + i_2 = \alpha$ ไม่ใช่ $i_2 = \alpha/2$ #พลาด/ข้ามขั้น
