# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้
id: O-1136
หัวข้อ: แรงและกฎนิวตัน
ระดับชั้น: ม.6
หัวข้อย่อย: คนดึงตัวเองบนแท่น
ระดับความยาก: 4
โจทย์: ชายมวล 60 kg ยืนบนแท่นมวล 20 kg เชือกเบาเส้นหนึ่งผูกติดกับแท่น พาดผ่านรอกตรึงบนเพดาน ปลายอีกข้างชายดึงไว้ ชายออกแรงดึงจนระบบอยู่นิ่งสมดุล (กำหนด $g=10$ m/s$^2$) จงหาแรงที่พื้นแท่นกระทำต่อชาย (หน่วย N)
หน่วย: N
คำตอบ: 200
คลาดเคลื่อน:
เฉลย: ให้แรงดึง $=T$ วิเคราะห์ชาย: $N+T=60g$ (พื้นดันขึ้น + เชือกดึงมือขึ้น = น้ำหนัก) วิเคราะห์แท่น: $T=20g+N$ (เชือกดึงแท่นขึ้น = น้ำหนักแท่น + ชายเหยียบลง) แก้สองสมการ: $T=200+600-T$ ได้ $T=400$ N และ $N=600-400=200$ N (ชายเบาตัวลงเพราะแรงดึงช่วยพยุง)
trap: ตอบ 400 — เอาแรงดึงเชือกมาตอบเป็นแรงพื้นกระทำ ลืมว่าถามแรง $N$ ระหว่างเท้ากับพื้น ไม่ใช่แรงในมือ #พลาด/แผนภาพแรง
trap: ตอบ 600 — ตอบน้ำหนักตัวเต็ม ($60g$) เหมือนยืนบนพื้นธรรมดา ลืมว่าแรงดึงเชือกช่วยพยุงตัวไว้ส่วนหนึ่ง #พลาด/เงื่อนไข
trap: ตอบ 800 — ตอบน้ำหนักรวมทั้งระบบ ($(60+20)g$) ลืมแยกคิดคนกับแท่นเป็นคนละก้อน #พลาด/ระบบ
