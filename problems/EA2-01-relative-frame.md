# ต้นฉบับของเรา (internal — origin: P'สิงหา/ทีม) — ขายได้ · ข้อสอบจำลอง A-Level ชุดที่ 2

หัวข้อย่อย: ความเร็วสัมพัทธ์และกรอบอ้างอิง
ระดับความยาก: 3

โจทย์: รถไฟแล่นบนรางตรงในแนวระดับด้วยความเร็วคงตัว 15.0 เมตรต่อวินาที ผู้โดยสารในตู้รถไฟปล่อยลูกบอลจากมือที่ระดับสูงจากพื้นตู้ 4.90 เมตร โดยไม่ออกแรงขว้าง ไม่คิดแรงต้านอากาศ
กำหนดให้: ความเร่งโน้มถ่วงของโลกเท่ากับ 9.8 เมตรต่อวินาที$^2$
คำถาม: ผู้สังเกตที่ยืนนิ่งอยู่บนพื้นดินข้างทางรถไฟ จะวัดระยะทางที่ลูกบอลเคลื่อนที่ได้ในแนวระดับกี่เมตร
ตัวเลือก A: $0$
ตัวเลือก B: $7.5$
ตัวเลือก C: $15.0$
ตัวเลือก D: $21.2$
ตัวเลือก E: $30.0$
คำตอบ: C
เฉลย: หาเวลาตกก่อนจาก $h=\frac{1}{2}gt^2$ : $4.90=\frac{1}{2}(9.8)t^2 \Rightarrow t^2=1.00 \Rightarrow t=1.00$ s

ขณะปล่อย ลูกบอลมีความเร็วในแนวระดับเท่ากับรถไฟอยู่แล้ว คือ $15.0$ m/s และไม่มีแรงในแนวระดับมากระทำ ความเร็วแนวระดับจึงคงตัวตลอด

ผู้สังเกตบนพื้นดินวัดได้ $s_x = v_x t = 15.0 \times 1.00 = 15.0$ เมตร
trap: ตอบ $0$ — สับสนกรอบอ้างอิง เอาคำตอบที่ผู้สังเกต "ในรถไฟ" เห็น (ลูกบอลตกลงตรงเท้าพอดี) มาตอบคำถามที่ถามจากกรอบพื้นดิน #พลาด/ระบบ #trap/28
trap: ตอบ $7.5$ — คิดว่าความเร็วแนวระดับลดลงจาก $15.0$ เหลือ $0$ แบบเดียวกับแนวดิ่ง แล้วใช้ความเร็วเฉลี่ย $\frac{15.0+0}{2}\times 1.00 = 7.5$ (จริง ๆ ไม่มีแรงในแนวระดับ ความเร็วจึงคงตัว) #พลาด/แยกแกน #trap/28
trap: ตอบ $21.2$ — รวมการกระจัดแนวระดับกับแนวดิ่งแบบพีทาโกรัส โดยใช้ระยะแนวดิ่งผิดเป็น $15.0$ ด้วย: $\sqrt{15^2+15^2}=21.2$ (คำถามถามเฉพาะแนวระดับ ไม่ต้องรวมเวกเตอร์) #พลาด/อ่านโจทย์
trap: ตอบ $30.0$ — ใช้เวลาตกผิดเป็น $2.00$ วินาที เพราะเผลอใช้ $h=gt^2$ (ลืมตัวหาร 2) แล้วได้ $15.0\times 2.00=30.0$ #พลาด/สูตรผิด #trap/1
