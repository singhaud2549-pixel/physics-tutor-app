# ให้ server เป็นแหล่งข้อมูลจริงของ Exam Session

Exam Mode ต้องให้ผลใกล้เคียงการสอบจริงพร้อมกับป้องกันคำตอบสูญหาย จึงให้ server เป็นผู้กำหนดเวลาเริ่ม เวลาสิ้นสุด สถานะ และคำตอบล่าสุดที่ยืนยันแล้วของ Exam Session ส่วน browser เก็บสำรองเพื่อช่วยกู้จากการขัดข้องเท่านั้นและไม่สามารถส่งคำตอบย้อนหลังหลังหมดเวลาได้ หากเหตุขัดข้องทำให้ข้อมูลไม่น่าเชื่อถือ ระบบจะระบุ session ว่าไม่สมบูรณ์และให้ผู้สอนอนุญาตเริ่มใหม่ แทนการลดความน่าเชื่อถือของผลสอบเพื่อรองรับการทำงานออฟไลน์เต็มรูปแบบ
