# ฝึกฟิสิกส์ — เฟส 1 (prototype)

เว็บทดลอง: นักเรียนทำโจทย์ 1 ข้อ พิมพ์คำตอบเป็นตัวเลข ถ้าผิด AI จะค่อย ๆ ใบ้ให้คิดต่อเอง (ไม่เฉลยตรง ๆ) จนทำถูก

เป้าหมายของเฟสนี้: **พิสูจน์ว่า AI ใบ้ดีพอไหม** ก่อนจะไปสร้างคลังโจทย์ / ล็อกอิน / ระบบอื่น

---

## วิธีรัน (ทำครั้งแรก)

> พิมพ์คำสั่งพวกนี้ใน Terminal โดยขึ้นต้นด้วย `!` ในหน้าต่างแชทของ Claude Code ก็ได้ (เช่น `! npm install`)

**1. ติดตั้งตัวช่วย (ทำครั้งเดียว)**
```
cd "/Users/singha/Desktop/physics-tutor-app"
npm install
```

**2. ใส่ API key ของ Claude**
- คัดลอกไฟล์ `.env.local.example` เป็นชื่อ `.env.local`
- เปิด `.env.local` แล้ววาง API key ของพี่ต่อท้าย `ANTHROPIC_API_KEY=`
- (API key เอามาจาก console.anthropic.com — ถ้ายังไม่มี บอกผมได้ เดี๋ยวพาทำทีละขั้น)

**3. เปิดเว็บ**
```
npm run dev
```
แล้วเปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

## ลองเล่นยังไง

โจทย์ตัวอย่าง: รถความเร็วต้น 10 m/s เร่ง 2 m/s² เป็นเวลา 5 วินาที หาความเร็วสุดท้าย
- คำตอบที่ถูกคือ **20**
- ลองตอบผิดดู เช่น `10` (ลืมบวกส่วนที่เร่ง) หรือ `45` (ไปหาระยะทางแทน) → ดูว่า AI ใบ้ดีไหม
- ตอบผิดหลาย ๆ ครั้งดู → AI ควรใบ้เจาะจงขึ้นเรื่อย ๆ แต่ไม่บอกคำตอบ

**สิ่งที่พี่ต้องประเมิน:** คำใบ้เหมือนครูที่ดีไหม? นำทางโดยไม่เฉลยไหม? ถ้ายังไม่โดนใจ บอกผมว่าอยากให้ปรับตรงไหน (เช่น ใบ้อ่อนไป/แรงไป, ภาษา, ความยาว) แล้วผมปรับที่ระบบให้
